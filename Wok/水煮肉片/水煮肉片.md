# 水煮肉片

川菜里的「下饭之王」——麻辣鲜香、肉片嫩滑、汤汁红亮。节奏是「先煮后泼油」，和大火快炒完全不同；学会了可以举一反三做水煮鱼、水煮牛肉。

## 🥩 食材清单（2 人份 · 带饭友好版）

**主料**

| 食材 | 用量 | 说明 |
| --- | --- | --- |
| 猪里脊肉 | 200-250g | 切薄片，约 2mm 厚，冻一下更好切 |

**配菜（垫底用，可自由替换）**

| 食材 | 用量 | 说明 |
| --- | --- | --- |
| 青菜 / 娃娃菜 | 2-3 棵 | 或油麦菜、豆芽、圆白菜均可 |
| 豆腐皮（可选） | 1 张 | 切丝，增加层次感 |
| 木耳（可选） | 几朵 | 提前泡发 |

**腌肉料**

| 调料 | 用量 | 说明 |
| --- | --- | --- |
| 料酒 | 1 勺（约 15g） | 去腥 |
| 生抽 | 1 勺（约 15g） | 底味 |
| 白胡椒粉 | 少许 | 去腥 |
| 盐 | 小半勺（约 2g） | 底味 |
| 玉米淀粉 | 2 勺（约 20g） | 嫩肉关键，裹住肉片防止煮老 |
| 蛋清 | 1 个（可选） | 让肉更嫩滑，但有人不喜欢会浮白沫 |
| 食用油 | 1 勺（约 15g） | 最后封油，防粘连 |

**炒汤底料**

| 调料 | 用量 | 说明 |
| --- | --- | --- |
| 郫县豆瓣酱 | 2 勺（约 30g） | 汤底红亮的关键，剁碎后香味更足 |
| 火锅底料 | 小块（可选） | 增加复合麻辣味，没有可只用豆瓣酱 |
| 姜 | 3-4 片 | 切片或切末 |
| 蒜 | 3-4 瓣 | 部分炒汤用，部分最后撒 |
| 花椒 / 麻椒 | 一小撮 | 分两份——炒汤用一份，最后撒一份 |
| 干辣椒 | 3-5 个 | 剪段 |

**汤底调味**

| 调料 | 用量 | 说明 |
| --- | --- | --- |
| 生抽 | 1 勺（约 15g） | — |
| 蚝油 | 1 勺（约 15g） | — |
| 白糖 | 小半勺（约 3g） | — |
| 盐 | 最后尝味再放 | 豆瓣酱本身有咸味 |

**最后泼油料**

| 调料 | 用量 |
| --- | --- |
| 蒜末 | 2-3 瓣（切末） |
| 葱花 | 适量 |
| 辣椒面 | 2 勺（约 15g） |
| 花椒粉 | 1 小勺（约 5g） |
| 食用油 | 约 50-70g（烧热泼油用） |

## 👨‍🍳 操作流程

1. **第一步：切肉 + 腌制（关键）**

    + 里脊肉放冰箱冷冻半小时，取出切成约 2mm 薄片——冻过的肉更好切均匀
    + 加料酒、生抽、白胡椒粉、盐、淀粉、蛋清（可选），朝一个方向抓匀——淀粉是嫩肉的核心，不能省
    + 最后淋入 1 勺食用油抓匀——油能锁住水分，下锅时肉片不易粘连
    + 腌制 15-20 分钟，让肉充分入味

2. **第二步：处理配菜**

    + 青菜洗净，豆腐皮切丝，木耳撕小朵
    + 锅中烧水，将配菜分别焯熟，捞出沥干——青菜煮到断生即可，别煮太久会烂
    + 将焯好的配菜铺在大汤碗或深盆底部

3. **第三步：炒汤底**

    + 锅倒油，下姜片、葱段、花椒爆香，加入郫县豆瓣酱（剁碎）和火锅底料（可选）（中小火）——炒到豆瓣酱出红油，这一步决定汤底颜色
    + 倒入开水（约 500-600ml），加生抽、蚝油、白糖调味（大火）——水量能没过肉片和配菜即可，不用太多
    + 大火煮开后，尝一下咸淡，不够再加盐——豆瓣酱本身有咸味，盐一定要最后尝过再放

4. **第四步：煮肉片（成败关键）**

    + 汤底煮开后，转最小火——大火下肉的话，肉片容易冲散，淀粉也会把汤弄浑
    + 用筷子一片一片把肉片放入锅中（小火）——不要一坨倒下去，会粘在一起
    + 肉片全部下完后，不要立刻搅动，等约 10 秒——让淀粉稍微凝固再推，肉片不易脱浆
    + 转中大火，煮到肉片变色、浮起（约 1-2 分钟）——肉片变白即可，别煮太久，会老
    + 连汤带肉一起倒入铺好配菜的碗中

5. **第五步：泼油（灵魂步骤）**

    + 在肉片上均匀撒上蒜末、辣椒面、花椒粉、葱花——撒得均匀一点，泼油才能均匀受热
    + 另起小锅，倒入约 50-70g 食用油，烧到微微冒烟（约 180-200℃）——油温一定要够高，才能激发出香味
    + 将热油分次泼在辣椒面和蒜末上——听到「滋啦」一声，香味就全出来了

## ✅ 成品标准

+ 肉片：嫩滑不柴，入口即化
+ 汤底：红亮浓郁，麻辣鲜香
+ 配菜：吸饱了汤汁，入味但不烂
+ 表面：一层红亮的油，蒜香和辣椒香扑鼻

## ⚠️ 翻车预警

| 翻车现象 | 原因 | 改进 |
| --- | --- | --- |
| 肉片煮老了、发柴 | ①煮太久 ②淀粉没抓够 | 肉片变色浮起就出锅，煮 1-2 分钟足够；淀粉给足，抓匀上浆 |
| 肉片下锅后淀粉脱落、汤变浑 | ①火太大 ②下锅后立刻搅动 | 转最小火下肉，下完后等几秒再轻轻推散 |
| 汤底颜色不够红亮 | 豆瓣酱没炒透 | 豆瓣酱炒出红油再加水，这一步是关键 |
| 泼油后不香 | 油温不够高 | 油要烧到微微冒烟再泼，温度够了才能激发出香味 |

## 💡 带饭专项

+ 适合带饭吗？
    ⚠️ 不太适合。肉片回热后容易变老，配菜也会变得更软烂，口感会打折扣
+ 如果一定要带
    把肉片和汤分装，回热时中低火加热，时间不要太长，避免肉片变柴
