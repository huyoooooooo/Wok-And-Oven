# 包菜粉丝炒蛋

经典家常快手菜：包菜脆爽、粉丝 Q 弹、鸡蛋鲜嫩，三种口感叠加，咸鲜入味，适合工作日快速搞定一顿饭。

## 🥩 食材清单（2 人份 · 带饭友好版）

| 食材 | 用量 | 说明 |
| --- | --- | --- |
| 干粉丝 | 60g | 红薯粉丝或龙口粉丝均可，碳水约等于 80g 生米 |
| 鸡蛋 | 150g（约 3 个） | 打散备用 |
| 包菜 | 250-300g | 切细丝，越细越容易炒软入味 |
| 大蒜 | 2-3 瓣 | 切末 |
| 干辣椒 | 2-3 个（可选） | 不吃辣可省略 |
| 食用油 | 25-30g | 炒制用 |

**碗汁（提前调好）**

| 调料 | 用量 | 说明 |
| --- | --- | --- |
| 生抽 | 2 勺（约 20g） | 咸鲜底味 |
| 蚝油 | 1 勺（约 15g） | 提鲜，也帮助粉丝上色 |
| 老抽 | 半勺（约 5g） | 主要给粉丝上色，让颜色更均匀 |
| 白糖 | 小半勺（约 3g） | 中和咸味，平衡口感 |
| 清水 | 2-3 勺（约 30-45g） | 防止炒的时候太干，帮助粉丝散开 |

## 👨‍🍳 操作流程

1. **第一步：预处理（成败关键）**

    + 粉丝用温水泡软（约 10-15 分钟），捞出沥干，用剪刀剪成 2-3 段——不要泡太久，否则炒的时候容易碎；剪短这一步很重要，吃的时候不容易缠成一团
    + 包菜切细丝，越细越容易熟透入味——切粗了炒不软，影响整体口感
    + 鸡蛋加少许盐打散，提前给一点底味
    + 碗汁提前调好备用

2. **第二步：炒蛋**

    + 热锅倒油，倒入蛋液快速划散（中大火，约 30 秒）
    + 炒到八成熟（表面刚凝固）就盛出备用——不要炒太老，后面还要回锅

3. **第三步：爆香**

    + 锅中补少许油，下蒜末和干辣椒爆香（中火，约 20 秒）

4. **第四步：炒包菜**

    + 下包菜丝，快速翻炒至变软、体积明显缩小（大火，约 1.5-2 分钟）
    + 全程大火，包菜才会脆爽不出水

5. **第五步：合炒粉丝**

    + 放入泡好的粉丝，淋入碗汁，快速翻炒均匀（中大火，约 30-40 秒）
    + 用筷子辅助翻炒更容易让粉丝散开

6. **第六步：加蛋出锅**

    + 倒回炒好的鸡蛋，翻炒均匀即可出锅（中大火，约 20 秒）
    + 鸡蛋回锅后刚好全熟，保持嫩度

## ✅ 成品标准

+ 包菜：软而不烂，脆爽入味
+ 粉丝：Q 弹爽滑，均匀裹上酱色，不坨不断
+ 鸡蛋：嫩滑，成块状不碎
+ 整体：干香不湿，不粘锅底

## ⚠️ 翻车预警

| 翻车现象 | 原因 | 改进 |
| --- | --- | --- |
| 粉丝炒碎了 | 泡太久或炒太久 | 温水泡 10-15 分钟即可，下锅后快速翻炒 |
| 粉丝成坨不散 | 沥水不够干或水加太多 | 泡好后充分沥干，碗汁里的水不要多加 |
| 包菜出水太多 | 火不够大或炒太久 | 全程大火快炒，包菜变软就马上进入下一步 |
| 鸡蛋炒老了 | 第一次炒到全熟 | 第一次炒到八成熟就盛出，留到合炒时刚好全熟 |

## 💡 带饭专项

+ 适合带饭吗？
    ✅ 非常适合
+ 粉丝会坨吗？
    - 炒的时候碗汁里的水不要收太干，留一点湿润度。装盒后自然冷却会吸收水分；
    - 第二天微波加热时中高火 2-3 分钟，中途搅拌一次，能最大程度还原口感
+ 加热要不要加水？
    微波加热前可以在表面淋几滴水，盖上盖子加热，利用蒸汽回软
+ 保鲜期
    冷藏 2 天，不建议冷冻
