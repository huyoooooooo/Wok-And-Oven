# 6寸古早蛋糕

定值配方；烫面 + 水浴，口感湿润绵软。

## ✅ 配方（6寸）

+ **【蛋黄糊】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 低筋面粉 | 55g | 提前过筛 |
    | 玉米油 | 45g | 加热到 70-80℃ |
    | 牛奶 | 50g | 常温 |
    | 蛋黄 | 3个（约 55-60g） | 冷藏鸡蛋分离 |

+ **【蛋白霜】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 蛋白 | 3个（约 100-105g） | 冷藏备用 |
    | 细砂糖 | 45g | 分 3 次加入 |
    | 柠檬汁/白醋 | 几滴 | 稳定蛋白，去腥 |

## ⏰ 烤箱设置

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火 |
| 温度 | 150℃ |
| 模具 | 6 寸固底或活底，底部和侧面铺油纸 |
| 位置 | 最下层（水浴） |
| 时间 | 65 分钟 |

## 👨‍🍳 制作流程

1. **第一步：准备模具**

    + 6 寸固底或活底模具，底部和侧面铺好油纸（油纸略高出模具边缘）
    + 活底模具：外面包两层锡纸，防止水浴进水

2. **第二步：烫面**

    + 玉米油加热到 70-80℃（油面出现细微纹路、手放在上方能感觉到热气即可）
    + 关火，加入过筛的低筋面粉，快速搅拌均匀，至无干粉状态
    + 加入牛奶，搅匀
    + 加入蛋黄，用刮刀或手动打蛋器 Z 字形搅拌均匀，至顺滑无颗粒

3. **第三步：打发蛋白霜**

    + 蛋白加入柠檬汁，细砂糖分 3 次加入（粗泡时加 1/3 → 细密小泡时加 1/3 → 出现纹路时加最后 1/3）
    + 打发到湿性发泡（大弯钩）：提起打蛋头，蛋白霜呈大弯钩且会微微晃动

4. **第四步：混合面糊**

    + 取 1/3 蛋白霜加入蛋黄糊，翻拌均匀
    + 倒回剩余蛋白霜中，继续翻拌至颜色均匀（约 20-30 下）

5. **第五步：入模与水浴**

    + 面糊从高处倒入模具，轻震两下排出大气泡
    + 烤盘里注入热水（约 1-1.5cm 高），将模具放入烤盘，放在烤箱最下层

6. **第六步：烘烤**

    + 150℃ 烤 65 分钟（低温慢烤是古早的关键）
    + 如果表面上色过快，可以在最后 20 分钟加盖锡纸

7. **第七步：出炉**

    + 出炉后不用倒扣，轻震一下排出热气
    + 连油纸一起拎出模具，放在晾网架上放凉

## 注意事项

+ 油温太高或太低：
    - 70-80℃ 最佳；过高会把面粉烫成面团，太低起不到烫面效果
+ 蛋白打发过度：
    - 打发到大弯钩（湿性发泡）即可；打到干性发泡会导致开裂、口感偏硬
+ 活底模具进水：
    - 外面必须包两层以上锡纸
+ 烘烤时间不够：
    - 古早需要低温慢烤；没烤熟会塌陷、底部湿黏
+ 出炉后塌陷：
    - 蛋白打发不够或没烤熟；建议烤完焖 5 分钟再出炉
+ 水浴用冷水：
    - 必须用热水/温水，冷水会让烤箱温度大幅下降
