# 6寸原味戚风

基础戚风配方；蛋白打到干性发泡，出炉必须倒扣。

## ✅ 配方（6寸）

+ **【蛋黄糊】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 低筋面粉 | 50g | 过筛 |
    | 细砂糖 | 15g | 蛋黄用 |
    | 玉米油（或植物油） | 30g | 无味植物油 |
    | 牛奶 | 35g | 常温 |
    | 蛋黄 | 3个（约 50-55g） | 冷藏鸡蛋分离 |

+ **【蛋白霜】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 蛋白 | 3个（约 100-110g） | 冷藏，无油无水无蛋黄 |
    | 细砂糖 | 35g | 蛋白用，分 3 次加入 |
    | 柠檬汁/白醋 | 几滴 | 稳定蛋白，去腥 |

## ⏰ 烤箱设置

提前 150℃ 预热（至少 10 分钟）

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火 |
| 温度 | 150℃ |
| 模具 | 6 寸，不刷油、不垫油纸 |
| 位置 | 中下层 |
| 时间 | 45-50 分钟 |

## 👨‍🍳 制作流程

1. **第一步：准备与预热**

    + 烤箱提前预热 150℃（至少 10 分钟）
    + 模具不要刷油、不要垫油纸

2. **第二步：制作蛋黄糊**

    + 蛋黄 + 15g 糖，用手动打蛋器搅打至颜色变浅、微微发白
    + 加入玉米油，搅打至完全融合（看不到油花）
    + 加入牛奶，搅匀
    + 筛入低筋面粉，用打蛋器 Z 字形搅拌（不要画圈），拌匀至无干粉即可

3. **第三步：打发蛋白霜**

    + 蛋白盆里加几滴柠檬汁
    + 电动打蛋器低速打至粗泡，加入 1/3 糖
    + 中速打至细密小泡，加入 1/3 糖
    + 中高速打至出现纹路，加入最后 1/3 糖
    + 继续打至干性发泡：提起打蛋头，蛋白霜呈直立小尖角，不弯曲

4. **第四步：混合**

    + 取 1/3 蛋白霜放入蛋黄糊，用刮刀翻拌均匀
    + 将混合物倒回剩余蛋白霜中，翻拌至颜色均匀（动作轻快，约 30 下左右）
    + 不要画圈搅拌

5. **第五步：入模与烘烤**

    + 面糊从约 15cm 高度倒入 6 寸模具
    + 轻震模具 2-3 下，排出大气泡
    + 放入预热好的烤箱，中下层，150℃ 烤 45-50 分钟
    + 判断熟度：蛋糕涨到最高点后回落，表面金黄，用竹签插入中心不带出湿面糊即熟

6. **第六步：出炉与倒扣**

    + 出炉后从 20cm 高度震一下模具（排出热气）
    + 立即倒扣在晾网架上
    + 完全晾凉（至少 2 小时）后才能脱模

## 注意事项

+ 蛋白打发：
    - 盆必须无油无水无蛋黄；打到干性发泡（直立小尖角）
+ 翻拌手法：
    - 从底部往上翻，动作轻快，不要画圈
+ 烘烤温度：
    - 每个烤箱实际温度不同，建议用温度计校准
+ 倒扣：
    - 出炉后必须立即倒扣，否则会塌陷
+ 脱模：
    - 完全凉透后再脱模
