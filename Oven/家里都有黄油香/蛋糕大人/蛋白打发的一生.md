# 蛋白打发

分蛋打发中，蛋白打发决定了一个蛋糕的命运，是其最后成品的关键。

1. 阶段一：**粗泡状态 (Foamy Stage)**

    + 状态描述：蛋白液表面出现许多透明、不规则的大气泡，像鱼眼一样，质地稀薄，流动性很强。
    + 判断方法：提起打蛋头，蛋白霜会直接滴落，无法在打蛋头上停留。
    + 适用场景：蛋白支撑力极低，不能用于制作蛋糕，否则会变成“蛋饼”。糖的第一次加入通常就在这个阶段。

2. 阶段二：**湿性发泡 (Soft Peak Stage)**
    
    + 状态描述：气泡变得细小且均匀，蛋白霜呈现白色、细腻、有光泽的奶油状。整体质地还比较软，有流动性，倾斜盆时会缓慢移动。
    + 判断方法：提起打蛋头，蛋白霜会形成一个弯曲的、向下垂的“小弯钩”（约1-2厘米），尖角会柔软地弯向地面。
    + 适用场景：制作轻乳酪蛋糕和慕斯的理想状态。

3. 阶段三：**中性发泡/湿性偏干 (Firm Peak Stage)**

    + 状态描述：蛋白霜的光泽度达到顶峰，内部气泡结构非常稳定，整体呈固态，倾斜盆子时完全不会流动，可以倒扣。
    + 判断方法：
        - 方法一：提起打蛋头，蛋白霜会呈“弯钩”或“鹰嘴”状。钩尖微微下垂，钩体直立。
        - 方法二：将打蛋盆倒扣，蛋白霜纹丝不动，绝对不会掉下来。
    + 适用场景：制作瑞士卷的理想状态。支撑力足够让蛋糕蓬松，柔软的弯钩又保证了卷起时的韧性，不易开裂。

4. 阶段四：**干性发泡 (Stiff Peak Stage)**

    + 状态描述：蛋白霜非常硬挺，表面干燥，缺乏光泽，看起来有颗粒感，甚至像棉花或硬奶油。
    + 判断方法：提起打蛋头，蛋白霜会形成一个短小、直立、完全不弯曲的尖角。打蛋头插入蛋白霜中心，能感觉到明显的阻力。
    + 适用场景：制作戚风蛋糕和分蛋海绵蛋糕的合格状态

5. 阶段五：过度打发 (Over-Whipped Stage)
    
    + 状态描述：挽回不了的失败状态。蛋白霜失去光泽，出现明显的豆腐渣状或棉絮状结块，盆底甚至会有出水现象。
    + 判断方法：蛋白霜变得粗糙、松散，无法再与其他材料混合均匀。
    + 补救建议：这个状态基本无法复原。如果出现这种情况，建议果断放弃，重新开始
