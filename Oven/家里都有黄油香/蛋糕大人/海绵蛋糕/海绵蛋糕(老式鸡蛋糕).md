# 海绵蛋糕（老式鸡蛋糕 · 马芬纸杯版）

全蛋打发的老式鸡蛋糕；扎实抗饿、蛋香浓。同一份量也可做 6 寸模具。

## ✅ 配方（6-8 个纸杯）

| 材料 | 克重 | 备注 |
| --- | --- | --- |
| 鸡蛋 | 3个（约 150g） | 室温，提前从冰箱取出回温 |
| 细砂糖 | 75g | 不要减糖，糖是打发的结构支撑 |
| 低筋面粉 | 80g | 过筛 |
| 玉米油或黄油（可选） | 10g | 传统配方不加；加了更润 |
| 牛奶（可选） | 10g | 跟油一起加 |
| 盐（可选） | 一小撮（约 0.5g） | 去蛋腥、提甜味 |

同一份量也可倒入 6 寸模具：温度调到 160℃，烤 30-35 分钟（面糊更厚）。

## ⏰ 烤箱设置（纸杯版）

提前 170℃ 预热约 10 分钟

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火同温 |
| 温度 | 170℃ |
| 层位 | 中层 |
| 时间 | 20-25 分钟 |
| 出炉标准 | 表面金黄，竹签插入中心不沾面糊 |

## 👨‍🍳 制作流程

1. **第一步：预热烤箱**

    + 170℃，上下火同温，提前预热 10 分钟

2. **第二步：全蛋打发（成败关键）**

    + 鸡蛋 3 个 + 细砂糖 75g，放入无油无水的打蛋盆中
    + 打蛋盆坐在 40-50℃ 热水上（隔热水打发，更容易打发）
    + 电动打蛋器高速打发：
        - 0-3 分钟：体积膨胀，颜色变浅，呈淡黄色
        - 3-5 分钟：颜色变白，蛋糊变浓稠，提起打蛋头有明显纹路
        - 5-8 分钟：提起打蛋头，蛋糊滴落能在表面画「8」字且 5 秒不消失 → 完成
    + 全蛋打发比蛋白打发难，一定要打到「写 8 字不消失」，否则会塌、不蓬松、像蛋饼

3. **第三步：拌入面粉（防消泡）**

    + 低筋面粉 80g 分两次筛入蛋糊中
    + 用刮刀从底部翻拌（不是搅拌）——从下往上翻，动作轻、快
    + 看不见干粉就停，不要多拌，否则消泡

4. **第四步：加入油和牛奶（可选）**

    + 若加玉米油 / 黄油和牛奶，在面粉拌好后最后加入，轻轻翻拌均匀即可

5. **第五步：分装到纸杯**

    + 马芬纸杯放入烤盘（6-8 个）
    + 勺子将面糊舀入纸杯，装到 7 分满
    + 轻轻震一下烤盘，震出大气泡

6. **第六步：烘烤**

    + 中层 170℃ 烤 20-25 分钟
    + 表面金黄，竹签插入中心不沾面糊即可出炉

7. **第七步：出炉冷却**

    + 取出后震一下烤盘，不用倒扣（老式鸡蛋糕结构稳定，不会回缩）
    + 转移到晾网冷却

## ⚠️ 关键注意事项

| 环节 | 注意点 |
| --- | --- |
| 全蛋打发 | 必须打到写「8」字 5 秒不消失；不够则塌、不蓬松 |
| 隔热水 | 40-50℃ 热水盆，更容易打发；水温不要烫手 |
| 拌粉 | 翻拌不是搅拌，看不见干粉就停，防消泡 |
| 装杯 | 7 分满，太满会溢 |
| 6 寸模具 | 同一份量可用；160℃ 烤 30-35 分钟 |
| 出炉 | 不用倒扣，震一下即可 |

## 📊 热量参考

| 版本 | 总热量 | ÷6 个 | ÷8 个 |
| --- | --- | --- |
| 基础版（无油无奶） | 约 800 千卡 | 约 133 千卡/个 | 约 100 千卡/个 |
| 加料版（+10g 油 +10g 奶） | 约 895 千卡 | 约 149 千卡/个 | 约 112 千卡/个 |

| 材料 | 贡献热量 | 占比（基础版） |
| --- | --- | --- |
| 细砂糖（75g） | 300 千卡 | 37% |
| 低筋面粉（80g） | 290 千卡 | 36% |
| 鸡蛋（3 个） | 210 千卡 | 26% |
| 油 + 奶（加料版） | +95 千卡 | 额外增加 |

热量来源很纯粹——碳水 + 鸡蛋，脂肪极低。这也是它「扎实抗饿」的原因：没有脂肪撑场面，全靠蛋和糖的结构。

| 版本 | 热量 | 口感 | 适合场景 |
| --- | --- | --- |

| 加料版（+10g 油 +10g 奶） | 约 149 千卡/个 | 更润、更软、不噎人 | 当早餐、给小朋友吃 |

## 💡 如果想再降低热量

| 调整方式 | 效果 |
| --- | --- |
| 减糖到 60g | 总热量降约 60 千卡，每个减约 10 千卡，但打发难度增加 |
| 去掉油（做基础版） | 总热量降约 90 千卡，每个减约 15 千卡，口感变干 |
| 用代糖（赤藓糖醇）替换部分糖 | 热量更低，但可能偏干、上色浅 |
| 牛奶换成水 | 热量几乎不变（10g 牛奶才约 5 千卡），没必要换 |
