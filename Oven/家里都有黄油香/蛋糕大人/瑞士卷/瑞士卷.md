# 28×28 原味瑞士卷

原味蛋糕体 + 抹茶奶油馅；蛋白打到湿性发泡即可，奶油必须打到硬挺再卷。

## ✅ 配方

+ **【蛋糕体（原味）】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 鸡蛋 | 5个（约 60g/个） | 蛋黄蛋白分离 |
    | 玉米油 | 40g | 无味植物油 |
    | 牛奶 | 50g | 常温 |
    | 低筋面粉 | 60g | 过筛 |
    | 细砂糖 | 45g | 蛋白用，分次加入 |
    | 柠檬汁 | 几滴 | 稳定蛋白 |

+ **【抹茶奶油馅】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 淡奶油 | 200g | 冷藏 12 小时以上 |
    | 糖粉/细砂糖 | 16-18g | 约 8-9% 比例 |
    | 抹茶粉 | 5-8g | 过筛后先用少量淡奶油化开 |

想做可可味：把抹茶粉换成可可粉 8-10g，操作方式一样。

## ⏰ 烤箱设置

提前 180℃ 预热

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火 |
| 温度 | 180℃ |
| 烤盘 | 28×28，铺油纸 |
| 时间 | 15-18 分钟 |

## 👨‍🍳 制作流程

1. **第一步：准备烤盘**

    + 28×28 烤盘铺油纸
    + 烤箱提前预热 180℃

2. **第二步：制作蛋黄糊**

    + 蛋黄 + 玉米油 + 牛奶搅匀
    + 筛入低筋面粉拌匀

3. **第三步：打发蛋白霜**

    + 蛋白 + 柠檬汁，分 3 次加糖
    + 打发至湿性发泡（大弯钩）

4. **第四步：混合与入模**

    + 取 1/3 蛋白霜与蛋黄糊翻拌，倒回剩余蛋白霜中翻匀
    + 面糊倒入烤盘，刮平，轻震两下

5. **第五步：烘烤与脱模**

    + 180℃ 烤 15-18 分钟，表面金黄、轻按回弹即可
    + 出炉后趁热撕掉油纸，盖新油纸防干，放凉

6. **第六步：奶油馅与卷制**

    + 淡奶油 + 糖打发至硬挺（出现明显纹路、提起打蛋头呈直立尖角）
    + 如果加抹茶粉：先取少量淡奶油与抹茶粉调匀，再与剩余奶油混合
    + 蛋糕片放凉后抹上奶油：靠近自己的一端抹厚一些，尾端抹薄
    + 用油纸辅助卷起，卷紧，放入冰箱冷藏定型至少 1 小时

## 注意事项

+ 蛋白打发：
    - 湿性发泡即可；打到干性发泡，卷的时候容易裂
+ 奶油打发：
    - 必须打到硬挺（直立尖角），否则卷的时候会漏
+ 卷制时机：
    - 蛋糕片放凉到手温再卷；太热奶油会化，太凉容易裂
+ 冷藏定型：
    - 至少 1 小时，切面才会整齐

## 🔪 切分与热量

+ **切分建议**
    - 常规：切成 8-10 片，厚度约 2.5-3cm
    - 切 8 片：每片约含 25g 奶油，比较满足
    - 切 10 片：每片约含 20g 奶油，更适合小份分享

+ **热量估算**（按 200g 淡奶油 + 16g 糖 + 蛋糕体）
    - 整个瑞士卷：约 1300-1500 大卡（蛋糕体约 800-900，奶油馅约 500-600）
    - 切 8 份：每份约 160-190 大卡
    - 切 10 份：每份约 130-150 大卡
    - 抹茶粉或可可粉的热量几乎可以忽略

## 🍰 为什么瑞士卷的蛋黄可不加糖？

+ 原理不同：
    - 戚风蛋糕需要蛋黄糊加糖增加乳化效果，帮助面糊稳定；
    - 不加糖的蛋黄糊，做出的戚风甜度略低，蛋糕体偏干（缺少了糖的保湿）
    - 瑞士卷的蛋黄糊即使不加糖，只要乳化做到位（油和牛奶充分搅匀），面糊也能撑住。

+ 糖的用途不同：
    - 瑞士卷的糖主要是在打发蛋白时加入，用来稳定蛋白霜的结构。

+ 口感差异不大：
    - 蛋黄糊加糖会让蛋糕体甜度更均匀。
    - 瑞士卷的风味更多来自奶油馅料，蛋黄糊不加糖也不会“寡淡”。
