# 奥利奥冰乳酪司康

成品 6 个；冷黄油切拌、不揉面。冷藏或冷冻后乳酪馅像冰淇淋。

## ✅ 配方（6个）

+ **【司康面团】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 低筋面粉 | 200g | 过筛 |
    | 细砂糖 | 15g | — |
    | 盐 | 1g | — |
    | 泡打粉 | 5g | — |
    | 无盐黄油 | 60g | 冷藏固体，切 1cm 小丁 |
    | 牛奶 | 60g | 冷藏 |
    | 淡奶油 | 50g | 冷藏 |
    | 奥利奥碎 | 35g | 市售现成碎，或奥利奥去夹心擀碎 |

+ **【乳酪馅】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 奶油奶酪 | 200g | 室温充分软化 |
    | 细砂糖 | 20g | — |
    | 耐高温巧克力豆 | 25g | — |

+ **【表面装饰（可选）】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 奥利奥碎（细粉状） | 适量 | 撒表面用 |

如果 50g 淡奶油不便：

| 替代方案 | 操作 | 成品变化 |
| --- | --- | --- |
| 50g 全脂牛奶 | 直接 1:1 换成牛奶 | 酥松度略降，没那么润，但区别不大 |
| 30g 牛奶 + 20g 融化的黄油 | 混合后加入 | 口感更接近原版 |

## ⏰ 烤箱设置

提前预热 170℃

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火 |
| 温度 | 170℃ |
| 层位 | 中下层 |
| 时间 | 20 分钟 |

## 👨‍🍳 制作流程

1. **第一步：提前准备**

    + 奶油奶酪提前取出，室温充分软化（约 1 小时，手指轻按无阻力）
    + 黄油切 1cm 小丁后放回冷藏备用
    + 烤盘铺油纸

2. **第二步：制作乳酪馅（先做，需冷冻定型）**

    + 软化奶油奶酪 + 细砂糖 20g，搅至完全顺滑无颗粒
    + 加入耐高温巧克力豆，翻拌均匀
    + 装入裱花袋，挤成 6 份（每份约 44g）在铺了油纸的盘子上
    + 冷冻定型约 30 分钟；取出搓圆，放回冷藏备用

3. **第三步：制作司康面团（冷黄油切拌，全程不揉面）**

    + 大盆：低筋粉 200g + 糖 15g + 盐 1g + 泡打粉 5g，搅匀
    + 加入冷藏黄油丁 60g，用刮板或手指切入面粉，搓成粗玉米粉状（无大块黄油即可）
    + 加入牛奶 60g + 淡奶油 50g，翻拌至无干粉即停（**不要揉面**）
    + 加入奥利奥碎 35g，翻拌均匀

4. **第四步：包馅**

    + 面团均分成 6 份（每份约 70-75g）
    + 每份用手压扁成圆饼（不要擀）
    + 中间放冷冻定型的乳酪馅球
    + 包起来，不完全收口——让乳酪馅稍微露出一部分
    + 表面撒少许奥利奥碎装饰

5. **第五步：烘烤**

    + 放入预热好的烤箱中下层，170℃ 烤 20 分钟
    + 烤至 12-15 分钟时，若表面颜色已深，盖锡纸防止上色过重
    + 出炉判断：司康体表面金黄，乳酪馅边缘微微冒泡即可

6. **第六步：冷却与享用**

    + 出炉后在烤盘上静置 5 分钟，再移到晾网彻底晾凉
    + 最佳吃法：冷藏 1 小时或冷冻 30 分钟后直接啃——乳酪馅像冰淇淋，司康体酥松

## 注意事项

+ 不揉面：
    - 翻拌至无干粉就停；揉出筋的司康不酥松
+ 黄油必须冷：
    - 全程保持固体状态，不能软化
+ 乳酪馅先冻：
    - 不冻定型会漏馅、烤时塌；至少冻够 30 分钟
+ 不完全收口：
    - 露出一部分乳酪馅，烤出来颜值更高；收口太松也会爆出来，适度捏紧
+ 烤到上色就盖纸：
    - 司康体含糖，上色快；12-15 分钟看一眼，颜色够了就盖锡纸；偏深可下次降到 160℃
+ 司康体太干/散：
    - 加 5g 牛奶补；翻拌到刚好成团即可
+ 冻啃时司康体太硬：
    - 冷冻 30 分钟即可，不是冻成石头；冷藏 1 小时效果更好
