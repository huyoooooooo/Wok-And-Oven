# 核桃马里奥（200g 麻薯粉）

麻薯体 + 脆壳淋面 + 海盐芝士奶油馅；表面沾核桃碎。

## ✅ 配方（200g 麻薯粉）

+ **【麻薯体】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 麻薯预拌粉 | 200g | — |
    | 全蛋液 | 60g | 约 1 个稍大的鸡蛋 |
    | 水 | 60g | 常温 |
    | 玉米油 / 黄油 | 60g | 黄油需提前融化 |

+ **【脆壳淋面】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 蛋白 | 48g | 约 1.5 个鸡蛋的蛋白 |
    | 细砂糖 | 40g | — |
    | 杏仁粉 | 24g | — |
    | 低筋面粉 | 8g | - |

+ **【海盐芝士奶油馅】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 奶油芝士 | 26g | 提前软化 |
    | 细砂糖 | 8g | — |
    | 盐 | 约 0.6g | 一小撮 |
    | 淡奶油 | 80g | 冷藏直接打发 |

+ **【表面装饰】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 核桃碎 | 适量 | 挤条后刷水/蛋液再沾 |
    | 水或蛋液 | 适量 | 刷表面，粘住核桃碎 |

## 🆚 淋面有几种做法？

| 淋面类型 | 操作 | 成品口感 | 卖相 |
| --- | --- | --- | --- |
| 打发蛋白派（本配方） | 蛋白 + 糖打发到 5 分，筛入粉类混匀 | 更蓬松、酥脆，口感更轻盈 | 能包裹住麻薯体，颜色更均匀 |
| 直接混合派 | 蛋白 + 糖粉 + 杏仁粉直接拌匀成糊状 | 更薄脆、硬挺，口感偏脆 | 像一层坚果糖衣，纹路更清晰 |

这两种做法的脆壳各有所长：一个更酥，一个更脆。

## ⏰ 烤箱设置

| 项目 | 参数 |
| --- | --- |
| 模式 | 平炉（上下火）/ 风炉 |
| 温度 | 平炉：上火 170℃ / 下火 160℃；风炉：160℃ |
| 时间 | 平炉 25-30 分钟；风炉 20-25 分钟 |

## 👨‍🍳 制作流程

1. **第一步：制作麻薯面糊**

    + 麻薯体全部材料放入盆中搅匀
    + 面糊偏粘，戴 PVC 手套防粘，揉到表面光滑、不粘手

2. **第二步：裱花与沾核桃**

    + 装入裱花袋，在烤盘上挤出约 12cm 长条
    + 表面刷一点水或蛋液，把核桃碎均匀沾上去

3. **第三步：脆壳淋面**

    + 蛋白加糖简单打发至呈流动的酸奶状
    + 筛入杏仁粉和低筋面粉拌匀
    + 装进裱花袋，呈「之」字形挤在麻薯表面

4. **第四步：烘烤**

    + 平炉：上火 170℃ / 下火 160℃，烤 25-30 分钟
    + 风炉：160℃，烤 20-25 分钟
    + 出炉后彻底晾凉再组装

5. **第五步：海盐芝士奶油馅**

    + 软化奶油芝士 + 糖 + 盐拌匀
    + 淡奶油打发至出现清晰纹路，与芝士糊翻拌均匀
    + 装入裱花袋备用

6. **第六步：组装**

    + 用刀在麻薯侧面划开一个口子（不用切断）
    + 把海盐芝士奶油挤进去

## 注意事项

+ 麻薯面糊：
    - 偏粘是正常的，戴手套揉到光滑不粘手即可
+ 淋面：
    - 蛋白糖打发到酸奶状就行，不要打过；干粉筛入后拌匀
+ 烘烤：
    - 平炉上下火温差可参考表内设置；风炉略降、略缩短时间
+ 组装：
    - 必须彻底晾凉再划开挤馅，否则奶油易化
