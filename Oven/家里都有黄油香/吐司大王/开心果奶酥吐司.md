# 开心果奶酥吐司（450g 带盖吐司盒 · 隔夜水合）

面团沿用隔夜水合；揉面时加入开心果酱。整形用麻花卷夹开心果奶酥馅。

## ✅ 配方（450g 带盖吐司盒）

+ **【面团】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 高筋面粉 | 250g | 蛋白质≥12% |
    | 细砂糖 | 30g | — |
    | 盐 | 3g | 第二天揉面时再放 |
    | 耐高糖干酵母 | 3g | 第二天揉面时再放，用少量液体化开 |
    | 全蛋液 | 40g | 水合用 |
    | 牛奶 | 140g | 水合先加 130g，预留 10g 化酵母/调整 |
    | 无盐黄油 | 30g | 室温软化，第二天后油法加入 |
    | 开心果酱（无糖纯酱） | 20g | 第二天与黄油同期加入 |

    开心果酱会吸水：牛奶先加 130g，第二天视面团软硬度决定是否补预留的 10g。

+ **【开心果奶酥馅】**（可提前一天做，或当天早上做）

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 无盐黄油 | 40g | 室温软化 |
    | 糖粉 | 25g | — |
    | 全蛋液 | 10g | — |
    | 奶粉 | 40g | — |
    | 开心果酱 | 15g | — |
    | 盐 | 1 小撮 | — |

+ **【表面装饰】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 全蛋液 | 适量 | 刷表面用 |
    | 开心果碎 | 15-20g | 去壳熟果仁切碎；二发后刷蛋液再撒 |

## ⏰ 烤箱设置

提前预热 170℃（比原版牛奶吐司低 5-10℃：果酱和奶酥含糖油，上色更快）

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火，带盖 |
| 温度 | 170℃ |
| 位置 | 中下层（与下加热管约 15cm） |
| 时间 | 35-38 分钟 |

## 👨‍🍳 制作流程

1. **第一步：隔夜水合 + 奶酥馅（第一天晚上）**

    + 水合：高筋粉 250g + 糖 30g + 蛋液 40g + 牛奶 130g → 混合至无干粉，盖保鲜膜冷藏 8-12 小时
    + **酵母、盐、黄油、面团用开心果酱都不要放进水合**
    + 奶酥馅：软化黄油 40g + 糖粉 25g 拌匀 → 加蛋液 10g 拌匀 → 加奶粉 40g + 开心果酱 15g + 盐 1 小撮，拌成顺滑膏状
    + 奶酥馅冷藏 15-20 分钟（变硬一点更好涂抹）；也可当晚做好备用

2. **第二步：揉面（第二天）**

    + 取出水合面团（已有厚膜），撕成小块；不用回温，直接操作
    + 加入盐 3g，揉至完全吸收（约 1-2 分钟）
    + 预留 10g 牛奶化开酵母 3g，揉入面团；面团偏干可再补约 5g 牛奶
    + 加入软化黄油 30g，揉至大致吸收
    + 加入开心果酱 20g，继续揉至手套膜（约 8-10 分钟）；破洞边缘光滑圆形
    + 面团呈淡绿色，比原版略软；出膜可能比原版快 2-3 分钟，提前检查

3. **第三步：一次发酵**

    + 面团滚圆，收口朝下，放入抹油大盆，盖保鲜膜
    + 约 30℃ 发酵至 2 倍大（约 50 分钟；40 分钟起检查）
    + 判断：手指戳洞，不回缩不塌陷

4. **第四步：麻花卷整形**

    + 操作台撒极薄一层手粉；从冰箱取出奶酥馅
    + 一发面团不分割，直接擀成约 30cm（宽）× 40cm（长）、厚约 0.5-0.6cm；擀不开就松弛 10 分钟再继续
    + 奶酥均匀涂在面片上，四周留 1cm 不抹；厚度约 2-3mm
    + 下半部分（靠近自己）纵向划条约 10-12 条，间隔约 2cm，划到距上边缘 1cm 处停（留连接带，不要划断）；用刮板或披萨刀，不要用钝菜刀
    + 每条捏住两端同向扭转 180°（最多不超过 360°），奶酥面朝外；全部顺时针或全部逆时针
    + 从上半部分（未划开处）向自己方向轻轻卷起，不要太紧；收口捏紧，收口朝下入模

5. **第五步：二次发酵 + 装饰**

    + 盖保鲜膜，约 30℃ 发 40-50 分钟，发到 **8 分满** 即入炉（35 分钟起检查；不要等 9 分）
    + 提前预热烤箱 170℃
    + 表面刷蛋液，撒开心果碎，轻轻按压让坚果陷入表面

6. **第六步：烘烤与冷却**

    + 170℃ / 中下层 / 带盖 / 35-38 分钟
    + 约 25 分钟起看色：表面已明显金黄就盖锡纸；最后 5 分钟再确认
    + 出炉：震一下 → 开盖 → 正着倒出 → 侧躺晾凉
    + 至少 2 小时后再用锯齿刀切片（凉透切面纹路才清晰）

## 注意事项

+ 揉面：
    - 开心果酱会让面团变软，出膜可能更快，提前检查手套膜
+ 擀面：
    - 麻花卷要比三卷法擀得更大（30×40cm）；回缩就松弛，不要硬擀破皮
+ 划条与扭转：
    - 不要划断上边缘；扭 180° 即可；漏出的奶酥用手轻轻按回
+ 二发：
    - 麻花结构内部有空气，膨胀比普通面团猛，8 分满就入炉
+ 高度：
    - 麻花卷吐司天然比三卷法略矮 1-2cm，属正常，不要为了高度延长二发
+ 烘烤：
    - 含糖油上色快，盯色盖锡纸；底部可垫油纸防漏馅
+ 收口：
    - 边缘留白、收口捏紧；漏一点不影响口感
