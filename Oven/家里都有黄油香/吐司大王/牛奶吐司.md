# 牛奶吐司（450g 吐司盒 · 隔夜水合）

面粉 + 糖 + 蛋液 + 牛奶提前一晚冷藏水合；第二天只揉入酵母、盐、黄油，约 15-20 分钟出手套膜。

## ✅ 配方（450g 吐司盒）

| 材料 | 克重 | 备注 |
| --- | --- | --- |
| 高筋面粉 | 250g | 蛋白质≥12% |
| 细砂糖 | 30g | — |
| 盐 | 3g | 第二天揉面时再放 |
| 耐高糖干酵母 | 3g | 第二天揉面时再放，用少量液体化开 |
| 全蛋液 | 30g | 约半个鸡蛋 |
| 纯牛奶（冷藏） | 150g | 先加 140g，预留 10g 调整 |
| 无盐黄油 | 25g | 室温软化，第二天揉面时再放 |

## ⏰ 烤箱设置

提前 10-15 分钟预热至设定温度

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火（平炉） / 风炉 |
| 温度 | 上下火 180℃；风炉 160℃ |
| 位置 | 上下火：下层；风炉：中层 |
| 时间 | 上下火 35-40 分钟；风炉 30-35 分钟 |

## 👨‍🍳 制作流程

1. **第一步：隔夜水合（第一天晚上，约 5 分钟）**

    + 大盆放入：高筋粉 250g + 细砂糖 30g + 全蛋液 30g + 冷藏牛奶 140g
    + 用筷子或刮刀搅拌至无干粉（面团粗糙、不成团没关系）
    + 盖保鲜膜，冰箱冷藏 8-12 小时
    + **酵母、盐、黄油绝对不要放进去**

2. **第二步：揉面（第二天）**

    + 从冰箱取出面团（已有厚膜，粗糙但能撑开）
    + 面团撕成小块，撒入盐 3g，揉至完全吸收（约 1-2 分钟）
    + 预留的 10g 冷藏牛奶（或 5g 水）化开酵母 3g，抹在面团上揉至吸收（约 2 分钟）
    + 包入软化黄油 25g，继续揉至手套膜
    + 手揉：摔打 + 折叠交替，约 12-15 分钟；厨师机：2 档 2 分钟至黄油吸收，转 4 档 6-8 分钟
    + 手套膜测试：能拉出均匀透明薄膜，破洞边缘光滑圆形（非锯齿）→ 成功

3. **第三步：一次发酵**

    + 面团滚圆，收口朝下，放入抹了薄油的盆中，盖保鲜膜
    + 28℃ 左右发酵至 2 倍大（约 1-1.5 小时）
    + 判断：手指沾干粉戳中心，洞口不回缩、不塌陷

4. **第四步：排气、分割、松弛**

    + 轻拍排气（不要揉，拍掉大气泡即可）
    + 均分成 3 份（每份约 155-160g），滚圆
    + 盖保鲜膜，室温松弛 15-20 分钟

5. **第五步：两次擀卷**

    + 第一次：收口朝上压扁，擀成约 20cm × 10cm，从上往下卷成圆柱（不要太紧）；全部卷好后再松弛 10 分钟
    + 第二次：收口朝上竖放，擀成约 30cm × 8cm，由上往下卷紧一点（不要卷死），收口朝下
    + 3 个面卷方向一致放入吐司盒（中间先放，两侧紧贴）

6. **第六步：二次发酵**

    + 盖保鲜膜或湿布，温暖处（35-38℃，湿度 80% 最佳）
    + 带盖方形：发至 8 分满（距顶部约 2cm）；不带盖山形：发至 9 分满
    + 约 1-1.5 小时，**看状态不看时间**；烤箱发酵功能可用，放一碗热水增湿

7. **第七步：烘烤**

    + 预热后放入吐司盒
    + 带盖方形：轻按顶部回弹 → 出炉，倒扣脱模
    + 不带盖山形：表面深金黄、轻按侧面回弹 → 出炉后侧躺晾网（防塌顶）
    + 顶部上色太快：入炉 10 分钟后盖锡纸（哑光面朝外）

8. **第八步：冷却与切片**

    + 出炉立即脱模，晾网上彻底冷却（至少 2 小时）
    + 完全凉透后用锯齿刀切片（热切会碎、组织塌陷）
    + 常温密封袋 3-4 天；切片冷冻约 1 个月（吃时复烤）

## 注意事项

+ 水合后太粘手：
    - 预留 10g 牛奶不要一次性加完；揉面时手上抹薄油防粘
+ 第二天面团偏硬：
    - 取出后室温回温 15 分钟再操作（冬天尤其需要）
+ 酵母揉进去后面团变稀：
    - 预留牛奶能化开酵母即可，不用全用完
+ 吐司不长高：
    - 酵母开封后冷藏保存；手套膜必须到位；二次发酵不超过 9 分满
+ 组织粗糙有大气孔：
    - 擀卷时用擀面杖轻压排气，边缘气泡用手拍掉
+ 出炉塌腰：
    - 延长 3-5 分钟烘烤；山形吐司出炉后侧躺晾凉
+ 切面掉渣：
    - 必须凉透再切，最好冷藏 1 小时后再切
