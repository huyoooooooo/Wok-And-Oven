# “种”

“种” 在中文面包语境下是一个从日语借词演化而来的“汉译”结果。

在日语中，“種”（读作 tane），本意是“植物发芽的种子”或“事物的起源”。

“种子”的诞生，核心在于预先发酵。日本面包师将预先发酵的面团部分称为“中種”（なかだね，Nakadane），字面意思就是“中间的种子”，因为它就像播种一样，将一小部分发酵好的面糊/面团作为“种子”，加入到主面团中去“繁衍”和“发酵。

最终给面包带来更浓郁的风味、更松软湿润的口感，以及更长的保鲜时间。

## 常见的 “种”

根据发酵剂和工艺的不同，面包的“种”主要可以分为两大类:

+ 利用商业酵母的**预发酵种**
    - 中种
    - 波兰种
    - 老面
+ 利用天然菌群的**天然酵种**
    - 鲁邦种
    - 果实种
    - 酒种

### 中种

配方中总面粉量的50%以上（最推荐70%）、全部或大部分酵母以及水混合而成

因初始面团中通常不含盐和油脂，酵母可以更活跃地进行发酵

中种法分为**快速法**（室温发酵约2-4小时）和**低温法**（冷藏发酵12-24小时），后者尤其适合家庭烘焙，可以灵活安排时间

1. 优点：
    + 面包更柔软：长时间的发酵和水合作用增加了面团的吸水量，成品更湿润，且在常温下能保持更长时间不干硬
    + 风味更丰富：长时间的发酵能产生更多的芳香物质，带来独特的发酵香气
    + 组织更细腻：面筋得到充分扩展，能更好地包裹气体，使面包体积更大，内部气孔均匀绵密
    + 面团操作性好：面团的延展性更强，不易回缩，在整形时更易操作，也更耐机械性处理

2. 制作:
    + **基本配方**：面团通常只需面粉、水、酵母。常见的70%中种比例：面粉（占总粉量70%）、水（约42%）、酵母（全部）。主面团包含剩余的面粉、水、盐、糖、油脂等。
    + 搅拌程度：面团混合成团无干粉，不需揉出薄膜。
    + **发酵判断**：发酵完成，面团体积膨胀3-4倍大，内部呈蜂窝或蜘蛛网状结构。面团缺乏弹性，拉扯易断裂，并散发浓郁的类酒精发酵气味

3. 应用品类
    + 各式吐司：中种法的“王牌应用”。无论是日式生吐司、白吐司或全麦吐司，都可极其柔软、拉丝明显，且放置2、3天依旧很润，不易变干。
    + 软式甜面包：如红豆包、菠萝包、奶油卷、汉堡胚等自身糖油含量较高。可以更加松软、化口性好，同时使浓郁的发酵香平衡甜腻感。
    + 调理面包：如热狗面包、肉松面包、芝士火腿面包等，需要承载馅料。强韧面筋，可使面包更有支撑力，不易塌陷

对柔软度和风味要求高的面包，想追求**软、绵、细**，首选中种

## 波兰种

这是一种“液态”的种，因起源于波兰而得名

1. 特点
    + 含水量极高：波兰种的面粉和水的比例为1：1（等量），搅拌后呈浓稠面糊状，而非面团。
    + 使用少量酵母：波兰种通常只使用配方中**总酵母量的25%~30%**，剩余酵母在主面团搅拌时才加入。需**较长时间**（通常是冷藏12-24小时）来慢慢发酵，以充分积累风味。

2. 制作
    + **基本配方**：面粉、水、酵母
    + 混合状态：混合均匀，搅拌至无干粉，最终呈顺滑的面糊状。盖保鲜膜，牙签扎几个小洞透气。
    + **发酵判断**：
        - 时间：室温发酵约3-4小时，或者冷藏发酵12-24小时。
        - 状态：发酵完成，表面布满大小不一气泡。内部呈蜘蛛网状结构。有浓郁的果香或酒酿般的甜香，非刺鼻的酸味。
        - 最终判断：用筷子挑起面糊，像绸缎般缓缓流下，而非断裂。

3. 使用要点
    + 水量要纳入计算：配方中主面团的水量需减去波兰种里用掉的水。如配方总水量是150克，波兰种用了50克水，那么主面团就只加100克水。
    + 无需回温：发酵好的波兰种可直接从冰箱取出使用，无需回温。冷藏的低温还可辅助控制主面团在搅拌时的温度，防止升温过快。

4. 应用品类(**硬欧包**为代表)
    + 法棍 (Baguette)：最经典的应用。赋予法棍标志性的蜂窝状大气孔、薄脆的外皮和浓郁的麦香与发酵香。
    + 乡村面包 (Pain de Campagne)：乡村风格的大圆面包，加入波兰种后，内部组织会变得更湿润、风味更复杂，外皮也更硬脆，带有明显的“欧包”质感。
    + 恰巴塔 (Ciabatta)：意式面包以含水量高、大气孔著称。波兰种正好能强化面筋，让面团在如此高的含水量下依然能保持形状，并形成其标志性的不规则大孔洞。

极致的湿润度和独特的风味的面包，想追求**润、香、脆**，可以试试波兰种

## 老面

有一个非常经典的来源：从上一批制作的面团中，特意留下一小块面团，冷藏保存，留作下一次使用。

本质上就是一块已经完全发酵好的“旧面团”。

家庭烘焙中更常用的是“配方老面”，即按固定配方（含面粉、水、酵母、盐）提前打出的面团，充分发酵后分装保存，随用随取。

1. 制作
    + 常用配方：高筋粉1000克、水680克、盐20克、鲜酵母10克。将所有材料搅拌至**完全扩展阶段（能拉出薄膜）**。
    + 发酵判断：室温（约25℃）发酵约1小时后，放入冰箱冷藏过夜，第二天即可使用。发酵好的老面，内部有丰富的蜂窝状组织，并散发着浓郁的酸香。
    + 保存方法：制作好的老面在冰箱冷藏可保存**3天左右**，冷冻则可以保存**1个月**。

2. 使用要点
    + 风味与酸味：长时间的发酵产生的乳酸等有机酸，给面包带来了复杂的风味层次，但用量过多会使面包偏酸，因此需严格控制20%以内
    + 用途：非常适合添加在需要醇厚风味和强韧口感的面包中，比如法棍、乡村面包等硬欧包，或用于制作风味更足的吐司。在中式面点里，也是制作老面馒头、包子的关键（通常要加碱中和酸味）

3. 应用品类
    + 🥖 硬质欧包（增加风味与爆发力）
        - 法棍和乡村面包：添加老面能让法棍的麦香更浓郁、更有层次感，同时外皮更脆，内部组织的嚼劲更足。许多法国面包师都会在配方中加入老面，来弥补直接法风味单一的不足。
        - 全麦面包和黑麦面包：全麦和黑麦粉本身口感较粗糙、缺乏弹性。加入老面可以显著提升面团的膨胀能力，让面包体积更大、内部更蓬松，同时中和粗粮的涩味，让风味更醇厚。
    + 🍞 风味型吐司（增加爆发力与醇厚感）
        - 全麦吐司、坚果/果干吐司：这些吐司加入大量辅料后会比较重，导致面团发酵时“撑不起来”。老面能增强面筋强度，提供更强的膨胀力，防止面包塌陷，同时赋予其更丰富的发酵香气。
    + 🥟 中式面点（传统应用）
        - 老面馒头、包子、花卷：这是老面的“传统艺能”，尤其是在酵母不普及时。用老面发酵的面点，吃起来嚼劲足、有面香、回味微甜。不过，老面发酵时间长了容易产生酸味，通常需要加少量食用碱（小苏打）来中和，才能得到松软洁白的成品。

### 中种、液种（波兰种）、老面对比表

| 对比维度 | 中种 (Sponge) | 液种 / 波兰种 (Poolish) | 老面 (Pâte Fermentée) |
| --- | --- | --- | --- |
| 外观状态 | 固态面团，揉成团即可，不粘手 | 液态面糊，面粉与水 1:1，像浓稠酸奶 | 固态面团，已揉出膜、完全发酵的面团 |
| 面粉占比 | 总粉量的 50%~100%（常用 70%） | 总粉量的 20%~40% | ≤ 总粉量的 20%（用量需控制） |
| 酵母用量 | 使用全部或绝大部分酵母 | 使用总酵母量的 25%~30% | 正常用量，先做一块完整面团 |
| 含水量 | 中等（约 60%~70%） | 极高（100%） | 中等（约 65%~70%） |
| 发酵时间 | 室温 2~4 小时 或 冷藏 12~24 小时 | 冷藏 12~24 小时（慢发酵为主） | 室温 1 小时 + 冷藏过夜 |
| 是否需要加盐 | 通常不加（盐会抑制酵母） | 不加 | 需要加（与主面团配方一致） |
| 核心作用 | 组织细腻、极致柔软、延缓老化 | 保湿性极佳、风味柔和、形成大气孔 | 增加风味层次、提升膨胀力、增强嚼劲 |
| 风味特点 | 浓郁的发酵香，酸味不明显 | 果香或酒酿般的甜香，酸味极淡 | 明显的乳酸菌酸香，复合风味 |
| 适用面包 | 日式生吐司、软式甜面包、汉堡胚 | 法棍、乡村面包、恰巴塔、软欧包 | 法棍、乡村面包、全麦面包、老面馒头 |
| 操作难度 | 简单 | 最简单 | 相对复杂（需先做一块完整面团） |
| 保存方式 | 现做现用，不适合长期保存 | 现做现用，不适合长期保存 | 冷藏 3 天 / 冷冻 1 个月 |

**一句话总结**

+ 想做极致柔软、拉丝细腻的吐司 → 选 中种
+ 想做外脆内润、有大孔洞的欧包 → 选 液种（波兰种）
+ 想增加面包的复合风味和嚼劲 → 选 老面（记得控制用量）

## **“天然酵种”**

依靠面粉、水、水果等原料自然吸附的野生酵母和乳酸菌来培养的。它风味最复杂，是面包师心中的“圣杯”。

+ 鲁邦种 (Levain / Sourdough)：这是最典型的天然酵种，主要用面粉和水培养，富含乳酸菌和醋酸菌。它能为面包带来丰富且有层次的微酸风味、漂亮的内部气孔，并极大延缓老化。制作传统的法式乡村面包或酸面包时，鲁邦种是灵魂所在。
+ 水果种 (Fruit Yeast Water)：用葡萄干、苹果等水果的发酵液培养而成。它会带有水果的清新香气，很适合制作甜面包或风味独特的点心面包。
+ 酒种 (Sake Yeast)：利用酒曲和大米培养，带有淡淡的米酒香气，能让面包口感湿润绵软，常用于制作日式红豆包等。


天然酵种（Sourdough Starter）对家庭烘焙确实不太“友好”, 固不展开介绍。

## 汤种和烫种

需要注意的汤种和汤种并不属于“发酵种”。其是物理变性，是一种“淀粉糊化种”。

本质是通过高温让面粉中的淀粉糊化，从而锁住水分，让面包极度柔软和保湿。

加入汤种的面包会更软糯、Q弹、保湿性极佳，但并不会带来发酵的香气

1. ⚖️ 汤种 vs. 烫种：核心区别

| 特性 | 汤种 (Yudane) | 烫种 (Tangzhong) |
| --- | --- | --- |
| 制作方式 | 将面粉与水（1:5）混合，加热至 65℃ | 将 100℃ 沸水直接冲入面粉（1:1）中 |
| 最终状态 | 浓稠浆糊状，可流动，像卡仕达酱 | 固态烫面团，不流动，像熟面疙瘩 |
| 含水量 | 更高（面水比 1:5），糊化程度较低 | 较低（面水比 1:1），糊化程度更彻底 |
| 成品特性 | 面包极其柔软、保湿性强，老化速度慢 | 面包 Q 弹有嚼劲，断口性更好，耐搅拌 |
| 操作难度 | 较简单，需要测温，不易失败 | 略复杂，开水操作需小心，不易揉匀 |
| 制作耗时 | 需冷却，通常冷藏 2 小时或过夜 | 需完全冷却，通常冷藏过夜 |

2. 📝 使用要点

    + 用量有上限：汤种/烫种通常建议为面粉总量的10%~30%。多了，面团的淀粉酶活性会被过度抑制，导致面团发黏、不好整形，甚至影响发酵。
    + 水量要算入配方：都含有大量水分，需从主面团的总水量中扣除。否则面团会过于湿黏。
    + 只“保湿”，不增风味：是纯粹的“物理保水剂”，不会像中种或天然酵种增加发酵的香气。

3. 🍞 使用品类

    + 日式生吐司：这是汤种的“王牌作品”，能做出云朵般柔软的组织。
    + 软式餐包/汉堡胚：让面包几天都不变硬，口感湿润。
    + 甜面包/调理面包：如菠萝包、肉松面包，能中和馅料带来的干涩感。
    + 部分软欧包：提升高含水量的软欧包的湿润度和弹性。

对于追求极致柔软和长保湿度的家庭烘焙来说，汤种和烫种是非常实用且成功率高的技巧。
