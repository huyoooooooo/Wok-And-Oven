# 开心果乳酪软欧（水合法 · 手揉）

牛舌状包乳酪条 + 纵向深割口；水合法冷藏静置，手揉出膜更省力，面温也好控。

## ✅ 配方（6 个，每个约 80g）

+ **【开心果面团】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 高筋面粉 | 250g | 蛋白质 ≥12% |
    | 展艺绿开心果酱（面团用） | 20g | 含姜黄、栀子黄、糖、盐 |
    | 细砂糖 | 22g | 酱里已有糖，所以减量 |
    | 盐 | 2g | 酱里已有盐，所以减量 |
    | 耐高糖干酵母 | 3g | 燕子 / 安琪 |
    | 全蛋液 | 25g | 约半个蛋 |
    | 冰牛奶 | 135g | 先加 130g，留 5g 调整 |
    | 无盐黄油 | 20g | 室温软化 |

+ **【乳酪馅】**（6 条，每条约 33g）

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | Kiri 奶油奶酪 | 200g | 室温彻底软化 |
    | 糖粉 | 28g | — |
    | 全脂奶粉 | 5g | — |
    | 柠檬汁 | 几滴（可选） | — |

+ **【表面撒粉 & 淋面】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 高筋面粉（撒表面） | 约 5-8g | — |
    | 展艺开心果酱（淋面） | 25g | — |
    | 糖粉（淋面） | 15g | — |
    | 牛奶 / 淡奶油（淋面） | 20-25g | 调成炼乳状 |
    | 开心果碎 | 15-20g | 淋面后撒 |

## ⏰ 烤箱设置

提前 180℃ 预热

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火 |
| 温度 | 180℃ |
| 时间 | 18-20 分钟 |
| 上色 | 表面金黄，割口乳酪微焦 |

## 👨‍🍳 制作流程

1. **第一步：乳酪馅预处理（先做，冷冻定型）**

    + Kiri 奶油奶酪室温彻底软化
    + 加入糖粉 28g、奶粉 5g、柠檬汁几滴，搅拌顺滑成厚膏状
    + 在油纸 / 保鲜膜上整形成 6 条长条（每条约 8-9cm 长、2cm 粗）
    + 冷冻 15-20 分钟定型（变硬能拿起来不弯折即可）

2. **第二步：水合法 —— 面团「自我醒发」（关键）**

    + 核心：除了酵母、盐、黄油，其他材料先混合，静置让面粉自己生成面筋
    + 大盆中加入：高筋面粉 250g + 细砂糖 22g + 开心果酱 20g + 全蛋液 25g + 冰牛奶 130g
    + 用筷子或刮刀搅拌成絮状，再揉成团（无需光滑，成团无干粉即可）
    + 盖保鲜膜，冰箱冷藏静置 30-60 分钟（夏天建议 60 分钟，冬天 30 分钟）
    + 静置后拉一下能看到粗糙的膜；大幅减少手揉时间，且面温不易升高

3. **第三步：揉入酵母、盐、剩余牛奶**

    + 取出冷藏静置好的面团
    + 表面挖小坑，放入干酵母 3g，倒入预留的 5g 冰牛奶（或一点点水）化开酵母
    + 掌根推、折叠、摔打，将酵母和牛奶揉进面团（约 3-5 分钟），直到均匀
    + 加入盐 2g，继续揉约 2-3 分钟，盐完全融入

4. **第四步：揉入黄油（手揉出膜）**

    + 将室温软化的黄油 20g 包入面团中间
    + 搓衣板揉面（掌根推出去、收回、旋转重复）
    + 刚开始会稀烂、油滑，不要慌，继续揉；约 5-8 分钟后黄油吸收，面团重新光滑有弹性
    + 继续揉 + 摔打：抓住一端甩在台上，对折再摔，重复
    + 总手揉约 15-20 分钟（比直接法省一半力气）
    + 检验：切一小块，能拉出薄而透光的手套膜，破洞边缘光滑无锯齿
    + 水合法要点：冷藏静置后面温仍低，最终面温易控在 26-28℃

5. **第五步：基础发酵（约 60-90 分钟）**

    + 面团滚圆，放入抹薄油的盆中，盖保鲜膜
    + 26-28℃ 发酵至 2 倍大
    + 检验：手指沾干粉戳洞，洞不回缩、不塌陷

6. **第六步：分割 & 松弛（约 20 分钟）**

    + 取出面团，轻拍排气
    + 分割成 6 等份（每个约 80g）
    + 滚圆，盖保鲜膜松弛 15-20 分钟

7. **第七步：包馅（牛舌状 + 条状馅）**

    | 步骤 | 操作 |
    | --- | --- |
    | ① | 面团擀成牛舌状（约 18-20cm 长、10-12cm 宽），中间稍厚、边缘薄 |
    | ② | 取出冷冻定型的乳酪条（每条约 33g），竖放在面片正中央 |
    | ③ | 从长边两侧往中间对折覆盖，或从上往下卷起包裹 |
    | ④ | 两端捏死（像拧糖纸），多余面团揪掉或往里折 |
    | ⑤ | 收口全部朝下，整形成长椭圆形（约 12-13cm） |

8. **第八步：最终发酵（约 40-50 分钟）**

    + 面包胚收口朝下摆在铺油纸的烤盘上，间隔 5cm 以上
    + 32-35℃、湿度 80%，发酵至 1.5 倍大
    + 检验：轻按表面，缓慢回弹

9. **第九步：撒粉 & 纵向深割口**

    + 细筛网在表面薄撒一层高筋面粉（约 5-8g）
    + 锋利刀片沿长轴正中央深割一刀：深度 1.5-2cm，长度 8-10cm，一刀到底，暴露内部乳酪馅

10. **第十步：烘烤**

    + 180℃ 上下火烤 18-20 分钟
    + 表面金黄、割口乳酪微焦即可

11. **第十一步：出炉冷却**

    + 震一下烤盘，转移到晾网
    + 彻底冷却至室温（约 30 分钟）

12. **第十二步：淋面 & 装饰**

    + 展艺开心果酱 25g + 糖粉 15g 混合，分次加入牛奶 / 淡奶油 20-25g，调成炼乳状
    + 淋在面包顶部，趁未凝固撒上开心果碎 15-20g
    + 静置 10 分钟凝固

## ⚠️ 关键注意事项

| 环节 | 常见问题 | 解决办法 |
| --- | --- | --- |
| 水合法静置 | 忘了放酵母，直接加盐 | 酵母和盐必须后加，不能和面粉一起静置 |
| 揉入黄油 | 面团稀烂、粘手 | 不要加粉；坚持揉 5-8 分钟，黄油吸收后会重新成团 |
| 手揉出膜 | 揉了 20 分钟还不出膜 | 多做摔打（甩出去、对折），比纯搓揉更高效 |
| 面温 | 揉面过程中面温升高 | 操作台不要太热；变温就冷藏 5-10 分钟再继续 |
| 乳酪馅冷冻 | 冻成冰块，无法贴合 | 冷冻 15-20 分钟即可，变硬能拿起来就够，别冻过夜 |
| 割口 | 割完后塌陷 | 二发不要过，1.5 倍大即止；刀要锋利，快速一刀 |

## ⏰ 操作时间轴

| 时间 | 操作 |
| --- | --- |
| 提前 30-60 分钟 | 乳酪馅调好 → 冷冻定型；面团水合法（除酵母盐黄油外混合 → 冷藏静置） |
| 0 分钟 | 取出面团，揉入酵母 → 盐 → 黄油，揉出手套膜 |
| +60~90 分钟 | 基础发酵（至 2 倍大） |
| +20 分钟 | 分割滚圆 → 松弛 |
| +15 分钟 | 包馅 → 整形 |
| +40~50 分钟 | 最终发酵（至 1.5 倍大） |
| +5 分钟 | 撒粉 → 割口 |
| +18-20 分钟 | 烘烤 |
| +30 分钟 | 冷却 |
| +5 分钟 | 淋面 → 撒开心果碎 |
