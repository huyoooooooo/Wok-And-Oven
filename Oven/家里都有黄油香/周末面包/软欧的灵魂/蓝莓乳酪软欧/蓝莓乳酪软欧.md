# 蓝莓乳酪软欧（水合法 · 手揉）

和开心果版同一套框架，风味换成蓝莓；注意果酱含水量和淋面稠度，这两个是蓝莓版特有的坑。

## ✅ 配方（6 个，每个约 80g）

+ **【蓝莓面团】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 高筋面粉 | 250g | 蛋白质 ≥12% |
    | 蓝莓果酱（面团用） | 25g | 建议用带果肉的，颜色和风味更好 |
    | 细砂糖 | 25g | 果酱里已有糖，比原味面团略减 |
    | 盐 | 3g | 果酱不含盐，保持正常量 |
    | 耐高糖干酵母 | 3g | 燕子 / 安琪 |
    | 全蛋液 | 25g | 约半个蛋 |
    | 冰牛奶 | 125g | 先加 120g，预留 5g 调整 |
    | 无盐黄油 | 20g | 室温软化，后加 |
    | 蓝莓干（可选） | 30g | 提前用温水或朗姆酒泡软，沥干后用 |

蓝莓果酱含水量差异大，牛奶一定要预留；果酱偏稀时，牛奶可减到 115g。

+ **【原味乳酪馅】**（6 条，每条约 33g）

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | Kiri 奶油奶酪 | 200g | 提前室温彻底软化 |
    | 糖粉 | 28g | 不要用细砂糖 |
    | 全脂奶粉 | 5g | 增加奶香和稠度 |
    | 柠檬汁 | 几滴（可选） | 解腻 |
    | 蓝莓果酱（馅料用，可选） | 20g | 拌入后馅更软，冷冻延长到 25-30 分钟 |

+ **【表面装饰 & 淋面】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 高筋面粉（撒表面） | 约 5-8g | 割口前薄撒一层 |
    | 蓝莓果酱（淋面用） | 25g | 太稠可加少量牛奶调稀 |
    | 糖粉（淋面用） | 15g | 增稠 + 平衡酸甜；果酱已很稠可减到 10g |
    | 牛奶 / 淡奶油（淋面用） | 15-20g | 调至炼乳状 |
    | 新鲜蓝莓或蓝莓干 | 15-20g | 淋面后趁未凝固撒上 |

蓝莓果酱通常比开心果酱稀，需加糖粉增稠，否则会流得到处都是。

## ⏰ 烤箱设置

提前 180℃ 预热

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火同温 |
| 温度 | 180℃ |
| 层位 | 中下层 |
| 时间 | 18-20 分钟（第 15 分钟观察） |
| 出炉标准 | 表面金黄 + 割口乳酪微焦 + 敲底有空心声 |

蓝莓果酱含糖，上色比开心果版略快；第 12 分钟观察一次，上色过快盖锡纸。

## 👨‍🍳 制作流程

1. **第一步：乳酪馅预处理（提前 30 分钟）**

    + Kiri 奶油奶酪室温彻底软化
    + 加入糖粉 28g、奶粉 5g、柠檬汁几滴，搅拌顺滑成厚膏状
    + 若加蓝莓果酱 20g，此时拌入搅匀
    + 整形成 6 条长条（每条约 8-9cm 长、2cm 粗）
    + 冷冻 20-30 分钟定型（加了果酱的馅更软，需冻久一点）

2. **第二步：水合法（提前一晚或当天）**

    | 时间 | 操作 |
    | --- | --- |
    | 前一晚（推荐） | 面粉 250g + 糖 25g + 蓝莓果酱 25g + 蛋液 25g + 牛奶 120g → 混合成团无干粉 → 盖保鲜膜 → 冷藏过夜（8-12 小时） |
    | 第二天 | 取出冷面团，挖坑放入酵母 3g + 预留牛奶 5g（化开酵母）→ 揉 3-5 分钟至吸收 → 加盐 3g 揉 2 分钟 → 加黄油 20g 揉 8-10 分钟至厚膜（破洞边缘少量锯齿即可） |

    + 水合法不放酵母、盐、黄油，这三样第二天再加
    + 蓝莓干若加，也在揉入黄油后、最后阶段轻轻揉进去

3. **第三步：基础发酵（60-90 分钟）**

    + 面团滚圆，放入抹油盆中，盖保鲜膜
    + 26-28℃ 发酵至 2 倍大
    + 检验：手指沾粉戳洞，洞不回缩、不塌陷

4. **第四步：分割 & 松弛（约 20 分钟）**

    + 取出面团，轻拍排气
    + 分割成 6 等份（每个约 80g）
    + 滚圆，盖保鲜膜松弛 15-20 分钟

5. **第五步：包馅（牛舌状 + 条状馅）**

    | 步骤 | 操作 |
    | --- | --- |
    | ① | 面团擀成牛舌状（约 18-20cm 长、10-12cm 宽），中间稍厚、边缘薄 |
    | ② | 取出冷冻定型的乳酪条（每条约 33g），竖放在面片正中央 |
    | ③ | 从长边两侧往中间对折覆盖，或从上往下卷起包裹 |
    | ④ | 两端捏死（像拧糖纸），多余面团揪掉或往里折 |
    | ⑤ | 收口全部朝下，整形成长椭圆形（约 12-13cm） |

6. **第六步：最终发酵（40-50 分钟）**

    + 面包胚收口朝下摆在铺油纸的烤盘上，间隔 5cm 以上
    + 32-35℃、湿度 80%，发酵至 1.5 倍大
    + 检验：轻按表面，缓慢回弹

7. **第七步：撒粉 & 纵向深割口**

    + 细筛网在表面薄撒一层高筋面粉（约 5-8g）
    + 锋利刀片沿长轴正中央深割一刀：深度 1.5-2cm，长度 8-10cm，一刀到底，暴露内部乳酪馅

8. **第八步：烘烤**

    + 180℃ 中下层烤 18-20 分钟
    + 第 12 分钟起观察上色，过快盖锡纸

9. **第九步：冷却**

    + 出炉后震一下烤盘
    + 转移到晾网彻底冷却至室温（约 30 分钟）
    + 热的时候不能淋面，会化掉流淌

10. **第十步：淋面 & 装饰**

    + 蓝莓果酱 25g + 糖粉 15g 混合
    + 分次加入牛奶 / 淡奶油 15-20g，调成炼乳状
    + 淋在面包顶部，趁未凝固撒上新鲜蓝莓或蓝莓干 15-20g
    + 静置 10 分钟凝固

## ⚠️ 关键注意事项

| 环节 | 常见问题 | 解决办法 |
| --- | --- | --- |
| 蓝莓果酱含水量 | 面团太黏 | 牛奶先加 120g，看状态再加；果酱偏稀则牛奶减到 115g |
| 乳酪馅加了果酱 | 馅料太软不好包 | 冷冻延长到 25-30 分钟，冻硬再包 |
| 蓝莓干 | 直接揉入会吸面团水分 | 提前泡软沥干，最后阶段轻轻揉入 |
| 割口 | 割太浅，馅不暴露 | 深割 1.5-2cm，刀要锋利，一刀到位 |
| 烘烤 | 上色过快 | 第 12 分钟观察，上色快盖锡纸 |
| 淋面 | 太稀挂不住 | 糖粉不能省，牛奶一点点加 |
| 淋面 | 颜色发暗 | 淋面不烤，出炉冷却后再淋 |

## 📦 保存

| 保存方式 | 时长 | 操作方法 |
| --- | --- |
| 常温密封 | 1-2 天 | 彻底冷却后密封，阴凉处；乳酪馅常温易变质，建议尽快吃 |
| 冷藏（推荐） | 3-5 天 | 密封冷藏；吃前微波 10 秒或烤箱 150℃ 复烤 3-5 分钟 |
| 冷冻 | 2-3 周 | 密封冷冻；吃前室温解冻 30 分钟，再 150℃ 复烤 5 分钟 |

淋面后建议冷藏保存；蓝莓淋面含糖粉和牛奶，常温放久了会化。

## ⏰ 操作时间轴（提前一晚水合版）

| 时间 | 操作 |
| --- | --- |
| 前一晚 | 乳酪馅调好 → 冷冻定型；水合法面团（无酵母盐黄油）→ 冷藏过夜 |
| 第二天 0 分钟 | 取出冷面团，揉入酵母 → 盐 → 黄油，揉至厚膜 |
| +60~90 分钟 | 基础发酵（至 2 倍大） |
| +20 分钟 | 分割滚圆 → 松弛 |
| +15 分钟 | 包馅 → 整形 |
| +40~50 分钟 | 最终发酵（至 1.5 倍大） |
| +5 分钟 | 撒粉 → 割口 |
| +18~20 分钟 | 烘烤（180℃ / 中下层） |
| +30 分钟 | 冷却 |
| +5 分钟 | 淋面 → 撒蓝莓 |
