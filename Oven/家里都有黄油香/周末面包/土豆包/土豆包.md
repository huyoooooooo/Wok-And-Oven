# 土豆包（热狗肠芝士版）

面包体 + 热狗肠土豆芝士馅 + 可可粉「泥土」装饰；外软内绵，带烟熏和拉丝层次。

## ✅ 配方（约 8 个）

+ **【面包体】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 高筋面粉 | 250g | — |
    | 奶粉 | 15g | 可选，增加奶香 |
    | 细砂糖 | 20g | — |
    | 盐 | 3g | — |
    | 干酵母 | 3g | 耐高糖酵母 |
    | 鸡蛋 | 1个（约 50g） | — |
    | 牛奶 | 130g | 根据面粉吸水性调整 |
    | 无盐黄油 | 20g | 室温软化，后油法加入 |

+ **【馅料】**（热狗肠 + 土豆 + 马苏里拉）

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 土豆 | 300g | 去皮后蒸熟压泥 |
    | 热狗肠 | 2-3 根 | 切碎或切成约 0.5cm 小丁 |
    | 马苏里拉芝士碎 | 50-80g | 增加拉丝效果 |
    | 盐 | 适量 | 调味 |
    | 黑胡椒粉 | 适量 | 调味 |

+ **【表面「泥土」装饰粉】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 可可粉 | 10g | 深色「泥土」效果 |
    | 奶粉 | 10g | 增加层次 |
    | 高筋面粉 | 20g | 让「泥土」更有质感 |

## ⏰ 烤箱设置

提前 165-170℃ 预热

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火 |
| 温度 | 165-170℃ |
| 层位 | 中层 |
| 时间 | 18-20 分钟 |

## 👨‍🍳 制作流程

1. **第一步：准备馅料 & 装饰粉**

    + 土豆去皮切块，蒸熟后压成泥
    + 热狗肠切成约 0.5cm 小丁
    + 土豆泥 + 热狗肠碎 + 马苏里拉芝士碎混合，加盐和黑胡椒粉调味
    + 分成 8 份（约 40-45g/份），搓圆备用；偏软可先冷藏 20 分钟再包
    + 可可粉 + 奶粉 + 高筋面粉混合均匀，作「泥土」装饰粉

2. **第二步：揉面**

    + 除黄油外，所有面团材料揉至扩展阶段
    + 加入软化的黄油，继续揉至手套膜

3. **第三步：一发**

    + 面团收圆，28℃ 发酵至 2 倍大（约 60-80 分钟）

4. **第四步：分割与松弛**

    + 发酵好的面团轻拍排气，均分成 8 份（约 55-60g/个）
    + 滚圆，盖保鲜膜松弛 15 分钟

5. **第五步：包馅整形**

    + 取一个松弛好的面团，擀开或用手压成圆片
    + 包入一份馅料（约 40-45g），收口捏紧（一定要捏紧，否则芝士会流出）
    + 整形成土豆的椭圆形，收口朝下

6. **第六步：裹「泥土」**

    + 在包好的面团表面喷一层薄薄的水雾
    + 放入装饰粉中滚一圈，表面均匀粘上「泥土」粉
    + 摆入烤盘，留出间距

7. **第七步：二发前做坑洞**

    + 用筷子或手指在面团表面轻轻戳出不规则坑洞，模拟土豆芽眼
    + 不要戳破面团，浅一些即可

8. **第八步：二发**

    + 32-35℃ 发酵至 1.5 倍大（约 30-40 分钟）
    + 二发后坑洞会稍微膨大，但轮廓还在

9. **第九步：烘烤**

    + 烤箱提前预热至 165-170℃
    + 中层烤 18-20 分钟
    + 表面有可可粉，上色不太明显，烤到面包体熟透即可

## ⚠️ 关键注意事项

| 要点 | 说明 |
| --- | --- |
| 收口一定要捏紧 | 热狗肠和芝士受热后流动性强，收口不紧容易爆馅、走样 |
| 戳洞要轻 | 二发前轻轻戳坑洞，不要戳破，否则芝士会从洞眼冒出 |
| 裹粉要均匀 | 喷水后再裹粉，轻轻按压让粉粘牢，烤后「泥土」不易脱落 |
| 热狗肠切碎度 | 约 0.5cm 小丁，不要太大，否则包的时候会撑破面团 |
| 馅料偏软 | 可先冷藏 20 分钟再包，更方便操作 |
