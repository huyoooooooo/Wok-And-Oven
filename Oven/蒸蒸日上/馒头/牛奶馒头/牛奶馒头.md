# 牛奶馒头（直接法 · 250g 面粉）

基于白面馒头配方，用水换成牛奶，糖量略提；成品更白更软，带淡淡奶香。

## ✅ 配方（250g 面粉）

| 材料 | 克重 | 备注 |
| --- | --- | --- |
| 中筋面粉 | 250g | 普通面粉即可 |
| 纯牛奶 | 135-140g | 室温或微温（约 25-30℃），比水多 10-15g |
| 干酵母 | 2.5-3g | 夏季 2.5g，冬季 3g |
| 细砂糖 | 15-20g | 比白面馒头多，能明显吃出清甜 |

牛奶比水稠，同样 125g 揉出来会偏干，所以加到 135-140g。

## 👨‍🍳 制作流程

1. **第一步：揉面（10-15 分钟）**

    + 面粉 + 酵母 + 糖在大盆中混合均匀
    + 分次加入牛奶，边加边用筷子搅拌成絮状
    + 上手揉成团，转移到案板上继续揉
    + 用掌根推压、折叠、反复揉，直到面团表面光滑、不粘手、有弹性
    + 判断标准：表面光滑、切面细腻无明显气孔即可，不需要出膜
    + 偏干可补 5-10g 牛奶；偏粘撒少量干粉即可

2. **第二步：一次发酵（约 50-60 分钟）**

    + 揉好的面团收圆，放入抹了薄油的盆中，盖上保鲜膜
    + 温暖处（约 28-30℃）发酵至 2 倍大
    + 手指沾干粉戳洞，洞口不回缩、不塌陷即完成

3. **第三步：排气（约 5-8 分钟）**

    + 发酵好的面团取出，案板上撒薄薄一层干粉
    + 用手掌根部用力推压、折叠、转 90° 再推压，重复操作
    + 排到切面光滑、没有明显气孔为止

4. **第四步：分割与整形（约 8-10 分钟）**

    + 排气好的面团搓成长条
    + 分割成 5 个剂子（每个约 80-85g）或 4 个剂子（每个约 100-105g）
    + 每个剂子滚圆收口，底部捏紧，形成光滑的馒头胚

5. **第五步：二次醒发（20-30 分钟）**

    + 馒头胚放入蒸笼（垫油纸或刷油防粘），留出约 1 个指节的膨胀空间
    + 盖上盖子，室温二次醒发，直到馒头胚明显变大一圈、拿起来轻飘飘的

6. **第六步：蒸制（18-20 分钟 + 焖 5 分钟）**

    + 冷水上锅，大火烧开至上汽
    + 转中大火，蒸 18-20 分钟（4 个做大个的话，20-22 分钟）
    + 关火后焖 5 分钟再开盖，防止回缩

## ⚠️ 关键注意事项

| 环节 | 注意点 |
| --- | --- |
| 牛奶温度 | 用室温牛奶，不要用冷藏的；偏凉会影响酵母活性 |
| 揉面手感 | 牛奶面团比白面略软、更顺滑，揉面时间差不多 |
| 一发判断 | 发酵膨胀会比白面略慢一点点，以 2 倍大为准 |
| 甜度 | 15-20g 糖能明显吃出清甜，空口吃就很好吃 |

## 🆚 和白面馒头的对比

| 对比 | 白面馒头 | 牛奶馒头 |
| --- | --- | --- |
| 液体 | 温水 125-130g | 牛奶 135-140g |
| 糖量 | 10g | 15-20g |
| 成品颜色 | 偏米白 | 更白 |
| 成品口感 | 扎实有嚼劲 | 更蓬松、更软 |
| 风味 | 纯粹麦香 | 奶香 + 清甜 |
