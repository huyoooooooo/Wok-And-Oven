# 红糖馒头（烫面法 · 250g 面粉）

烫面约占粉量 40%（100g 面粉烫面），成品比普通红糖馒头更软更 Q 弹，风味更浓郁；口感更像红糖发糕和馒头的结合体，放凉后也不易变硬。

## ✅ 配方（250g 面粉）

+ **【烫面部分】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 中筋面粉 | 100g | — |
    | 红糖 | 40g | 与烫面面粉混合 |
    | 开水 | 110g | 冲入红糖面粉中（约 95-100℃） |

+ **【主面团部分】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 中筋面粉 | 150g | — |
    | 干酵母 | 2.5g | — |
    | 常温水 | 约 60-70g | 根据面团状态调整 |

## 👨‍🍳 制作流程

1. **第一步：红糖烫面（约 5 分钟 + 放凉 15-20 分钟）**

    + 取 100g 面粉 + 40g 红糖，在大盆中混合均匀
    + 冲入 110g 开水，用筷子快速搅拌，直到红糖完全化开、面粉被烫透，形成褐色浓稠糊状烫面
    + 放置一旁，完全放凉至手温（约 30-35℃）

2. **第二步：混合主面团（约 10-12 分钟）**

    + 在放凉的烫面糊中，加入 150g 面粉 + 2.5g 酵母
    + 分次加入常温水（约 60-70g），边加边揉——先加 60g，面团偏干再补 10g
    + 揉成光滑、不粘手的面团；烫面红糖面团会比白面略粘，揉到位后依然光滑
    + 偏干少量补水，偏粘少量补粉

3. **第三步：一次发酵（约 50-60 分钟）**

    + 揉好的面团收圆，放入抹了薄油的盆中，盖上保鲜膜
    + 温暖处（约 28-30℃）发酵至 2 倍大
    + 手指沾干粉戳洞，洞口不回缩、不塌陷即完成

4. **第四步：排气（约 5-8 分钟）**

    + 发酵好的面团取出，案板上撒薄薄一层干粉防粘
    + 用手掌根部用力推压、折叠、转 90° 再推压，重复操作
    + 排到切面光滑、没有明显气孔为止
    + 红糖面团比白面更粘，撒粉不要过多，刚好防粘即可

5. **第五步：分割与整形（约 8-10 分钟）**

    + 排气好的面团搓成长条
    + 分割成 5 个剂子（每个约 75-80g）或 4 个剂子（每个约 95-100g）
    + 每个剂子滚圆收口，底部捏紧，形成光滑的馒头胚

6. **第六步：二次醒发（20-30 分钟）**

    + 馒头胚放入蒸笼（垫油纸或刷油防粘），留出约 1 个指节的膨胀空间
    + 盖上盖子，室温二次醒发，直到馒头胚明显变大一圈、拿起来轻飘飘的

7. **第七步：蒸制（18-20 分钟 + 焖 5 分钟）**

    + 冷水上锅，大火烧开至上汽
    + 转中大火，蒸 18-20 分钟（4 个做大个的话，20-22 分钟）
    + 关火后焖 5 分钟再开盖，防止回缩

## 🆚 烫面版 vs 普通版

| 对比 | 普通版红糖馒头 | 烫面版红糖馒头 |
| --- | --- | --- |
| 操作方法 | 所有材料直接混合揉面 | 先做烫面糊，放凉后再加干粉揉面 |
| 口感 | 扎实有嚼劲 | 更软、更 Q 弹 |
| 颜色 | 浅褐色 | 更深、更均匀 |
| 风味 | 红糖味和麦香层次分明 | 红糖风味更浓郁，融合更充分 |
| 老化速度 | 第二天变硬明显 | 第二天依然较软 |

## ⚠️ 关键注意事项

| 环节 | 注意点 |
| --- | --- |
| 烫面温度 | 冲入开水后一定要完全放凉至手温才能加酵母，否则酵母会被烫死 |
| 红糖预处理 | 红糖如果有结块，先碾碎再过筛，否则烫面中会有硬块化不开 |
| 揉面手感 | 烫面红糖面团比白面更粘手，揉到光滑不粘手即可，不要因为粘手就拼命加粉 |
| 一发 | 发到 2 倍大即可，不要超过 2.5 倍，否则会有酸味 |

| 0:32 | 一次发酵（约 50-60 分钟） |

## 💡 常见问题排查

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 红糖烫面有硬块 | 红糖没有提前过筛 | 红糖先碾碎再过筛后再和面粉混合 |
| 面团比白面更粘手 | 红糖本身带糖蜜，这是正常现象 | 案板上少撒粉，继续揉到光滑即可 |
| 成品不够 Q 弹 | 烫面比例偏少 | 下次增加烫面比例（150g 面粉烫面） |
| 红糖风味不够浓郁 | 红糖用量偏少 | 下次增加到 45-50g |
