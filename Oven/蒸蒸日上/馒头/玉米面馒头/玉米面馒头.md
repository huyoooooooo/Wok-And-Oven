# 玉米面馒头（烫玉米面 · 300g 粉类）

玉米面和白面搭配，带着粗粮香气和微微颗粒感，比白面馒头更有嚼劲，膳食纤维也更丰富。关键是玉米面先用开水烫过，口感会好很多。

## ✅ 配方（粉类合计约 300g）

| 材料 | 克重 | 备注 |
| --- | --- | --- |
| 中筋面粉 | 200g | 白面部分 |
| 玉米面 | 100g | 面粉：玉米面 = 2:1 |
| 开水 | 100g | 烫玉米面用（约 95-100℃） |
| 干酵母 | 3g | 粉类总量约 300g，按 100:1 |
| 细砂糖 | 10g | 提味，也可不加 |
| 温水 | 约 100-110g | 调整面团软硬度 |
| 猪油或玉米油 | 5-10g（可选） | 缓解粗粮口感偏干 |

## 👨‍🍳 制作流程

1. **第一步：烫玉米面（约 3 分钟 + 放凉 15 分钟）**

    + 玉米面 100g 放入盆中
    + 冲入开水 100g，用筷子快速搅拌，直到完全烫透，呈湿润的颗粒状或糊状
    + 放凉至手温（约 35℃）再继续；烫面能去生涩味，口感更细腻

2. **第二步：混合揉面（约 10-12 分钟）**

    + 在放凉的烫玉米面中，加入中筋面粉 200g + 酵母 3g + 糖 10g
    + 分次加入温水（约 100-110g），边加边揉成光滑面团
    + 玉米面没有筋性，面团会比白面粗糙、松散；揉到「表面相对光滑、不粘手」即可
    + 玉米面吸水更强：偏干少量补温水，偏粘少量补白面粉

3. **第三步：一次发酵（约 50-60 分钟）**

    + 揉好的面团收圆，放入盆中，盖上保鲜膜
    + 温暖处（约 28-30℃）发酵至 2 倍大
    + 手指沾干粉戳洞，洞口不回缩、不塌陷即完成
    + 玉米面发酵后气孔会比白面大一些，正常

4. **第四步：排气（约 5-8 分钟）**

    + 发酵好的面团取出，案板上撒薄薄一层干粉
    + 用手掌根部推压、折叠，重复操作，排掉大气泡
    + 排到切面没有明显大气孔为止
    + 颗粒感较重，不必追求白面那种细腻无气孔的切面

5. **第五步：分割与整形（约 8-10 分钟）**

    + 排气好的面团搓成长条
    + 分割成 5-6 个剂子（每个约 70-80g）
    + 每个剂子滚圆收口，底部捏紧
    + 延展性差，收圆时比白面容易开裂，手法要轻柔

6. **第六步：二次醒发（20-30 分钟）**

    + 馒头胚放入蒸笼（垫油纸或刷油防粘），留出膨胀空间
    + 盖上盖子，室温二次醒发，直到馒头胚明显变大一圈、拿起来轻飘飘的

7. **第七步：蒸制（15-18 分钟 + 焖 5 分钟）**

    + 冷水上锅，大火烧开至上汽
    + 转中大火，蒸 15-18 分钟
    + 关火后焖 5 分钟再开盖，防止回缩

## ⚠️ 关键注意事项

| 环节 | 注意点 |
| --- | --- |
| 玉米面用开水烫 | 烫过更细腻、无生涩味；一定要放凉到不烫手再和酵母混合，否则酵母会被烫死 |
| 玉米面和白面比例 | 面粉：玉米面 = 2:1 较稳妥；玉米面超过 50% 很难成团，口感偏散 |
| 揉面手感 | 比白面松散、粗糙，揉到「不粘手」即可，不必追求白面那种光滑细腻 |
| 发酵判断 | 膨胀程度比白面略小，以 2 倍大为准，不要盲目延长发酵时间 |

## 🆚 和白面、牛奶、红糖馒头的对比

| 对比 | 白面馒头 | 牛奶馒头 | 红糖馒头（烫面版） | 玉米面馒头 |
| --- | --- | --- | --- | --- |
| 主要粉类 | 中筋面粉 250g | 中筋面粉 250g | 中筋面粉 250g | 白面 200g + 玉米面 100g |
| 液体 | 温水 125g | 牛奶 135-140g | 开水 110g + 水 60g | 开水 100g + 温水 100g |
| 口感 | 扎实有嚼劲 | 蓬松柔软 | 软 Q 弹牙 | 粗糙有颗粒感、偏扎实 |
| 风味 | 纯麦香 | 奶香清甜 | 红糖焦香 | 玉米清香 |
| 膳食纤维 | 低 | 低 | 低 | 高 |

## 💡 和普通馒头的区别

玉米面没有面筋，全靠白面里的面筋撑结构。玉米面比例越高，越不容易蓬松，口感也越偏扎实、粗糙。面粉：玉米面 = 2:1 是粗粮馒头里比较稳妥的入门比例，既能吃到玉米香，又不会因粗粮太多影响发酵。

想更浓郁的玉米味，可以把玉米面提到 150g、白面降到 150g（1:1），需适当增加液体量，揉面也更耐心一些。
