# 白面馒头（直接法 · 250g 面粉）

基于已验证的 250g 中筋面粉基础款。想柔软保湿试烫面法，想风味嚼劲试老面法。

## ✅ 配方（250g 面粉）

| 材料 | 克重 | 备注 |
| --- | --- | --- |
| 中筋面粉 | 250g | 普通面粉即可 |
| 温水 | 125-130g | 约 30-35℃，手摸不烫 |
| 干酵母 | 2.5g | 夏季 2.5g，冬季可加至 3g |
| 细砂糖 | 10g | 帮助酵母活化，成品几乎不甜 |

## 👨‍🍳 制作流程

1. **第一步：揉面（10-15 分钟）**

    + 面粉 + 酵母 + 糖在大盆中混合均匀
    + 分次加入温水，边加边用筷子搅拌成絮状
    + 上手揉成团，转移到案板上继续揉
    + 用掌根推压、折叠、反复揉，直到面团表面光滑、不粘手、有弹性
    + 刚开始会黏手，正常，继续揉，不要急着加干粉
    + 判断标准：表面光滑、切面细腻无明显气孔即可，不需要出膜

2. **第二步：一次发酵（约 50-60 分钟）**

    + 揉好的面团收圆，放入抹了薄油或撒了干粉的盆中
    + 盖上保鲜膜，放在温暖处（约 28-30℃）
    + 发酵至 2 倍大，手指沾干粉戳洞，洞口不回缩、不塌陷即完成

3. **第三步：排气（约 5-8 分钟）**

    + 发酵好的面团取出，放在案板上（撒薄薄一层干粉防粘）
    + 用手掌根部用力推压、折叠、转 90° 再推压，重复操作
    + 排到切面光滑、没有明显气孔为止

4. **第四步：分割与整形（约 8-10 分钟）**

    + 排气好的面团搓成长条
    + 分割成 5 个剂子（每个约 75-80g）或 4 个剂子（每个约 95-100g）
    + 每个剂子滚圆收口，底部捏紧，形成光滑的馒头胚

5. **第五步：二次醒发（20-30 分钟）**

    + 馒头胚放入蒸笼（垫油纸或刷油防粘），留出约 1 个指节的膨胀空间
    + 盖上盖子，室温二次醒发，直到馒头胚明显变大一圈、拿起来轻飘飘的

6. **第六步：蒸制（18-20 分钟 + 焖 5 分钟）**

    + 冷水上锅，大火烧开至上汽
    + 转中大火，蒸 18-20 分钟（4 个做大个的话，20-22 分钟）
    + 关火后焖 5 分钟再开盖，防止回缩

## ⚠️ 关键注意事项

| 环节 | 注意点 |
| --- | --- |
| 揉面初期黏手 | 正常现象，不要急着加粉，面筋形成后黏度会下降 |
| 一发 | 发到 2 倍大即可，不要超过 2.5 倍，否则会有酸味 |
| 排气判断 | 切面光滑、没有明显气孔才算排好 |
| 二发判断 | 馒头胚明显变大、拿起来轻飘飘即可上锅 |
| 蒸制 | 全程中大火，中途不要开盖，关火后焖 5 分钟再开 |

| 时间 | 操作 |

## 💡 常见问题排查

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 馒头表面塌陷 / 回缩 | 焖的时间不够 | 延长焖制时间到 5-8 分钟 |
| 馒头组织偏紧、不暄软 | 排气不到位或二发不足 | 排气揉到切面无气孔，二发到明显变大 |
| 馒头有酸味 | 发酵过度 | 一发不要超过 2.5 倍，缩短发酵时间 |
| 表面有麻子脸 | 锅盖滴水或冷凝水滴落 | 用纱布包锅盖或留一条缝 |
