# 白面馒头（烫面法 · 250g 面粉）

部分开水烫面锁住水分，成品柔软、绵密、放凉后也不易发硬。烫面约占粉量 32%。

## ✅ 配方（250g 面粉）

+ **【烫面部分】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 中筋面粉 | 80g | 占总粉约 32% |
    | 开水（95-100℃） | 90-95g | 约粉水比 1:1.1 |

+ **【主面团部分】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 中筋面粉 | 170g | 剩余面粉 |
    | 温水（约 30℃） | 约 70g | 根据面团状态调整 |
    | 干酵母 | 2.5g | — |
    | 细砂糖 | 10g | 帮助发酵，成品几乎不甜 |

## 👨‍🍳 制作流程

1. **第一步：烫面（约 3 分钟 + 放凉 15 分钟）**

    + 取 80g 面粉放入盆中，冲入 90-95g 开水，用筷子快速搅拌成絮状
    + 完全放凉至手温（约 30-35℃）——烫面必须凉透才能和主面团混合，否则会烫死酵母

2. **第二步：混合揉面（约 12-15 分钟）**

    + 在放凉的烫面中加入 170g 面粉 + 2.5g 酵母 + 10g 糖
    + 分次加入温水（约 70g），边加边揉，直到光滑不粘手
    + 烫面本身含水量高，主面团的水量可以视情况调整
    + 揉面时会感觉面团比普通馒头更柔软、更「听话」，正常

3. **第三步：一次发酵（约 50-60 分钟）**

    + 面团收圆，盖保鲜膜，温暖处（28-30℃）发酵至 2 倍大
    + 戳洞判断：洞口不回缩、不塌陷

4. **第四步：排气与分割（约 5-8 分钟）**

    + 取出面团，案板上撒薄粉，揉搓排掉大气泡
    + 分成 5-6 个剂子（每个约 70-80g），滚圆收口

5. **第五步：二次醒发（20-30 分钟）**

    + 馒头胚放入蒸笼，留出膨胀空间
    + 醒发至明显变大、轻飘飘的

6. **第六步：蒸制（15-18 分钟 + 焖 5 分钟）**

    + 冷水上锅，上汽后中大火蒸 15-18 分钟
    + 关火后焖 5 分钟再开盖，防止回缩

## 🆚 烫面法 vs 老面法

| 对比 | 烫面法 | 老面法 |
| --- | --- | --- |
| 核心原理 | 开水烫面锁住水分 | 长时间发酵产生风味 |
| 口感 | 柔软、绵密、细腻 | 紧实、有嚼劲、越嚼越香 |
| 风味 | 单纯的麦香和淀粉回甘 | 麦香 + 酒香复合风味 |
| 老化速度 | 慢（放凉后依然柔软） | 中等，比酵母法略慢 |
| 操作时间 | 约 2.5 小时（无需提前准备） | 需提前一晚做老面 |
| 适合场景 | 想吃软馒头、当天决定做 | 追求风味、提前有准备 |

## ⚠️ 关键提醒

+ 烫面必须完全放凉再混合主面团，否则酵母会被烫死
+ 烫面比例 32% 是「半烫面」：既能保持柔软，又不会失去支撑力。全烫面（100%）口感会变粘；太少（＜20%）柔软效果不明显
+ 揉面时比普通面团更湿润、更柔软，正常，不要因此额外加太多干粉
+ 想对比口感，可同一天做一锅烫面法、一锅老面法，蒸好后对比着吃
+ 烫面法风味偏清淡，主要体现麦香和柔软度；老面法风味更丰富、更有层次
