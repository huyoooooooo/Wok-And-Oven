# 南瓜馒头（老面法 · 南瓜粒 · 250g 面粉）

老面约占粉量 28%（70g 面粉），南瓜粒生切直接揉入，黄冰糖调色增甜。成品白里透黄、紧实弹牙、颗粒散布。需提前一晚做老面。

## ✅ 配方（250g 面粉）

+ **【老面（提前一晚）】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 中筋面粉 | 70g | — |
    | 水 | 50g | 约 70% 含水量 |
    | 干酵母 | 0.5g | — |

+ **【主面团】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 中筋面粉 | 180g | 补足总粉 250g |
    | 老面（全部） | 约 120g | — |
    | 黄冰糖粉 | 30g | 打磨成粉或擀碎 |
    | 干酵母 | 1g | 补充发酵力 |
    | 水 | 约 70-80g | 视面团状态调整 |
    | 食用碱 | 1g | 用水化开，中和老面酸味 |

+ **【南瓜粒】**

    | 材料 | 克重 | 备注 |
    | --- | --- | --- |
    | 生南瓜（去皮） | 80g | 切黄豆大小，生粒直接揉入，不压泥 |

## 👨‍🍳 制作流程

1. **第一步：制作老面（提前一晚，约 5 分钟）**

    + 70g 面粉 + 50g 水 + 0.5g 酵母，混合揉成团（不用光滑）
    + 盖保鲜膜，室温发酵 4 小时后转入冰箱冷藏 12-18 小时
    + 第二天取出，室温回温 30 分钟再用

2. **第二步：主面团揉面（约 12-15 分钟）**

    + 黄冰糖 30g 用料理机打成粉，或装入保鲜袋用擀面杖擀碎
    + 大盆中放入中筋面粉 180g + 黄冰糖粉 30g + 干酵母 1g + 食用碱 1g（碱用 10g 水化开），混合均匀
    + 将回温的老面撕成小块加入，再分次加入水（约 70-80g），揉成光滑不粘手的面团
    + 加入生南瓜粒 80g（去皮切黄豆大小），轻轻揉匀，让南瓜粒散布在面团中

3. **第三步：一次发酵（约 60-90 分钟）**

    + 面团收圆，放入盆中盖保鲜膜，温暖处（28-30℃）发酵
    + 发酵至 2 倍大，手指沾干粉戳洞，洞口不回缩、不塌陷即可
    + 老面发酵速度比纯酵母慢，时间会比普通馒头略长

4. **第四步：排气与分割（约 8 分钟）**

    + 面团取出，案板上撒薄粉，揉搓排掉大气泡（约 3-5 分钟）
    + 分割成 5-6 个剂子（每个约 70-80g）
    + 每个剂子滚圆收口，底部捏紧

5. **第五步：二次醒发（20-30 分钟）**

    + 馒头胚放入蒸笼，留出膨胀空间
    + 室温二次醒发至明显变大、拿起来轻飘飘的

6. **第六步：蒸制（15-18 分钟 + 焖 5 分钟）**

    + 冷水上锅，大火烧开至上汽，转中大火蒸 15-18 分钟
    + 关火后焖 5 分钟再开盖，防止回缩

## ⚠️ 关键注意事项

| 环节 | 注意点 |
| --- | --- |
| 老面状态判断 | 好的老面扒开内部呈蜂窝状，有淡淡酒香。表面发霉或明显酸臭味则已变质，不能用 |
| 食用碱的用法 | 老面发酵会产生酸味，加碱中和后馒头更白更香。碱量只加 1g，用水化开后揉入（直接放粉状碱可能揉不匀） |
| 南瓜粒的处理 | 切黄豆大小，不要太大也不要太碎。生的直接揉入，不要蒸熟，不用压成泥 |
| 揉面力度控制 | 加入南瓜粒后轻轻揉匀即可，不要用力过猛，避免把南瓜粒揉烂 |
| 黄冰糖粉 | 一定要磨成粉再用，否则揉面时无法化开，成品会有冰糖硬块 |
| 发酵时间 | 老面法整体发酵比普通酵母馒头慢，一发需 60-90 分钟，看状态不看时间 |

## ✅ 成品特征

| 特征 | 描述 |
| --- | --- |
| 颜色 | 白里透着淡淡的暖黄色，主要来自黄冰糖和老面本身，南瓜粒不染色 |
| 口感 | 紧实弹牙、有嚼劲（老面法的标志性口感） |
| 风味 | 麦香 + 酒香复合，黄冰糖的清甜，比白砂糖更柔和 |

## 🆚 与普通白面馒头

| 对比 | 普通白面馒头 | 老面南瓜粒馒头 |
| --- | --- | --- |
| 发酵方式 | 纯酵母（一次性发酵） | 老面 + 酵母（两段式发酵） |
| 颜色 | 米白色 | 白里透着淡黄 |
| 口感 | 松软 | 紧实有嚼劲 |
| 风味 | 单纯麦香 | 麦香 + 酒香复合风味 |
| 操作时间 | 约 2.5 小时 | 需提前一晚做老面（总时长 12-18 小时） |

## ⏰ 操作时间轴

| 时间 | 操作 |
| --- | --- |
| 前一晚 | 老面制作（5 分钟）→ 室温发酵 4 小时 → 放冰箱冷藏过夜 |
| 第二天 9:00 | 取出老面回温（30 分钟） |
| 9:30 | 混合主面团揉面（12-15 分钟） |
| 9:45 | 一次发酵（60-90 分钟） |
| 11:15 | 排气、分割、整形（8 分钟） |
| 11:25 | 二次醒发（20-30 分钟） |
| 11:55 | 蒸制（15-18 分钟 + 焖 5 分钟） |
| 12:18 | 出锅 |

总用时约 2.5-3 小时（不含老面冷藏时间），实际动手时间约 35 分钟。
