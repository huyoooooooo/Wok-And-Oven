# 桃酥（玉米油版 · 100g 面粉）

加泡打粉补足玉米油版膨发力；约做 9 个。面团偏软正常，靠冷藏整形。

## ✅ 配方（约 9 个）

| 材料 | 克重 | 备注 |
| --- | --- | --- |
| 低筋面粉 | 100g | — |
| 玉米淀粉 | 15g | 降低筋度，增加酥松感 |
| 细砂糖（或糖粉） | 40g | 糖粉裂纹更漂亮，细砂糖也能用 |
| 盐 | 0.5g（一小撮） | 提甜味 |
| 小苏打 | 1g | 膨发 + 酥松 |
| 泡打粉 | 1.5g | 辅助膨发，补足玉米油版膨发力不足 |
| 玉米油 | 60g | 比猪油版略少 5g，防止面团过稀 |
| 全蛋液 | 13g（约 1/4 个鸡蛋） | 剩下的蛋液留着刷表面 |
| 核桃碎（可选） | 15g | 不放就是原味版 |
| 黑芝麻（装饰） | 适量 | 每个顶部撒几粒 |

玉米油比猪油稀，面团会偏软，需要通过冷藏来补救。

## ⏰ 烤箱设置

提前 170℃ 预热

| 项目 | 参数 |
| --- | --- |
| 模式 | 上下火同温 |
| 温度 | 170℃ |
| 层位 | 中层 |
| 时间 | 18-20 分钟 |
| 观察 | 最后 2 分钟盯着；上色比猪油版快，深金黄即出炉 |

## 👨‍🍳 制作流程

1. **第一步：混合液体材料**

    + 大碗中放入玉米油 60g + 细砂糖 40g + 盐 0.5g
    + 用蛋抽充分搅打约 2-3 分钟，直到糖基本融化、混合物变浓稠发白（不能省，否则成品偏硬）
    + 加入全蛋液 13g，继续搅打至完全融合，呈顺滑膏状

2. **第二步：混合干性材料**

    + 另一个碗中：低筋面粉 100g + 玉米淀粉 15g + 小苏打 1g + 泡打粉 1.5g
    + 用蛋抽或筷子充分混合均匀

3. **第三步：干湿混合（关键）**

    + 将干粉筛入玉米油混合物中
    + 用刮刀翻拌 / 切拌至无干粉即可，不要过度搅拌
    + 加入核桃碎 15g（不放就跳过），轻轻拌匀
    + 面团会比猪油版偏软、偏散，正常；不要揉成光滑团，翻拌到成团就行

4. **第四步：冷藏松弛**

    + 面团盖保鲜膜，冰箱冷藏 20-30 分钟
    + 冷藏后面团变硬一些，更容易整形

5. **第五步：分割整形**

    + 取出冷藏好的面团，分割成 9 份（每份约 25-26g）
    + 搓圆后放在铺了油纸的烤盘上，间隔 5cm 以上（烤时会膨胀摊开）
    + 掌心轻轻压扁成直径约 5-6cm 的圆饼，厚度约 1cm（不要太薄）
    + 用大拇指在正中间按一个深坑（比猪油版按深一点，玉米油版膨胀力度弱）
    + 表面刷一层薄薄的全蛋液（用刚才剩下的蛋液）
    + 每个中间撒几粒黑芝麻

6. **第六步：烘烤**

    + 170℃ 中层烤 18-20 分钟
    + 建议第 16 分钟透过玻璃门看一眼：已深金黄就提前出炉；颜色还浅再烤到 18-20 分钟

7. **第七步：冷却**

    + 出炉后不要移动（刚出炉是软的，移动会碎）
    + 在烤盘上自然冷却 10 分钟，定型后再转移到晾网
    + 彻底冷却后才会变酥（约 30 分钟）

## ⚠️ 关键注意事项

| 容易翻车的点 | 解决办法 |
| --- | --- |
| 面团太稀，压扁后塌成一滩 | 冷藏延长到 30-40 分钟；压扁不要太薄（约 1cm） |
| 烤出来偏硬、不酥 | ① 糖+油搅打不够发白，多搅 2 分钟 ② 面团揉过头起筋了，翻拌到无干粉就停 |
| 裂纹不明显，表面平整 | 中间按坑不够深；或压扁时厚度不够 |
| 颜色太深 / 焦了 | 玉米油上色快，下次降到 165℃，或缩短到 16-17 分钟 |
| 一拿就碎 | 冷却前移动了，彻底冷却后再拿 |

## 📦 保存

| 保存方式 | 时长 | 操作方法 |
| --- | --- | --- |
| 常温密封（推荐） | 7-10 天 | 彻底冷却后，密封罐 / 密封袋，阴凉干燥处 |
| 冷藏 | 2-3 周 | 密封冷藏，吃之前回温 10 分钟（口感更酥） |
| 冷冻 | 1-2 个月 | 密封冷冻；吃之前可不回温，150℃ / 5 分钟复烤 |

| 要点 | 说明 |
| --- | --- |
| 必须彻底冷却再密封 | 有余温就密封，水汽会让桃酥变软 |
| 防潮是关键 | 最怕受潮；密封罐可放食品干燥剂或一块方糖吸湿 |
| 复脆方法 | 放久变软，150℃ 复烤 3-5 分钟，冷却后恢复酥脆 |

## ⏰ 操作时间轴

| 时间 | 操作 |
| --- | --- |
| 0 分钟 | 玉米油 + 糖 + 盐 + 蛋液搅打至发白 |
| 5 分钟 | 筛入粉类，翻拌成团 |
| 6 分钟 | 面团冷藏（20-30 分钟） |
| 26 分钟 | 分割 → 搓圆 → 压扁 → 按坑 → 刷蛋液 → 撒芝麻 |
| 35 分钟 | 入炉烘烤（170℃ / 中层 / 18-20 分钟） |
| 55 分钟 | 出炉 → 烤盘上冷却 10 分钟 |
| 65 分钟 | 转移到晾网彻底冷却（约 30 分钟） |
| 95 分钟 | 完全冷却，密封保存 |

总用时约 1.5 小时（含冷却）。
